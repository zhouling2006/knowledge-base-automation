### 习题1.4

1. 下列说法是否正确？为什么？

（1）无穷大与有界函数的乘积是无穷大；  
(2) 无穷大与有界函数的和是无穷大;  
（3）无穷大与任意常数的乘积是无穷大；  
（4）两个无穷大的和是无穷大.

2. 根据定义证明：

（1） $\lim_{x\to 2}\frac{x}{x^2 - 4} = \infty$

(2) $\lim_{x\to 0}x\cos x = 0$

3. 指出下列极限过程中的函数，哪些是无穷大，哪些是无穷小：

(1) $f(x) = \frac{x - 1}{x^2 - 1}, x \to -1$ ;

(2) $f(x) = \ln x, x \to 1^{-}$ ;

(3) $f(x) = \mathrm{e}^{\frac{1}{x}}, x \to 0^{+}$ ;

(4) $f(x) = \frac{\pi}{2} - \arctan x, x \to +\infty$ .

4. 下列各函数，在 $x$ 的什么变化趋势下是无穷小？在 $x$ 的什么变化趋势下是无穷大？

(1) $y = \frac{x + 1}{x^3 - 1}$ ;

(2) $y = \sqrt{2x - 1}$ ;

(3) $y = \mathrm{e}^{x}$ ;

(4) $y = \cot x (0 < x < \pi)$ .
