### 一、二分法

设函数 $f(x)$ 在 $[a, b]$ 上连续， $f(a) \cdot f(b) < 0$ ，且方程 $f(x) = 0$ 在 $(a, b)$ 内仅有一个实根 $\xi$ ，则区间 $[a, b]$ 为实根 $\xi$ 的一个隔离区间.

二分法的基本思想是：取区间 $[a,b]$ 的中点 $\xi_{1} = \frac{a + b}{2}$ ，计算 $f(\xi_1)$ 。这时有如下两种可能

（1）若 $f(\xi_1) = 0$ ，则 $\xi = \xi_{1}$   
（2）若 $f(\xi_1) \neq 0$ ，则 $f(\xi_1)$ 与 $f(a), f(b)$ 中的一个异号。如果 $f(\xi_1)$ 与 $f(b)$ 异号，则 $\xi_1 < \xi < b$ 且 $b - \xi_1 = \frac{1}{2}(b - a)$ ；如果 $f(\xi_1)$ 与 $f(a)$ 异号，则 $a < \xi < \xi_1$ 且 $\xi_1 - a = \frac{1}{2}(b - a)$ 。若把 $\xi_1$ 作为方程根的近似解，其误差不超过 $\frac{1}{2}(b - a)$ 。

如果上述误差尚不能达到要求，可以对新的隔离区间 $[\xi_1, b]$ 或 $[a, \xi_1]$ 重复上面做法求得 $\xi_2$ （显见 $\xi_2 = \frac{\xi_1 + b}{2}$ 或 $\xi_2 = \frac{a + \xi_1}{2}$ ）。当 $\xi_2 \neq \xi$ 时，再重复上面做法，直至达到所需的精确度为止。

例3.7.1 求方程 $x^{3} - 2x^{2} - 4x - 7 = 0$ 在[3,4]上的一个近似根，要求误差不超过0.1.

解 设 $f(x) = x^{3} - 2x^{2} - 4x - 7$ ，则 $f(x)$ 在[3,4]上连续. 因为

$$
f (3) = - 1 0 <   0, f (4) = 9 > 0,
$$

所以方程 $f(x) = 0$ 在(3,4)内至少有一实根. 又 $f'(x) = 3x^2 - 4x - 4$ ，令

$$
f ^ {\prime} (x) = 3 x ^ {2} - 4 x - 4 = 0,
$$

解得 $x_{1} = -\frac{2}{3}, x_{2} = 2$ 当 $x > 2$ 时 $f^{\prime}(x) > 0$ ，函数 $f(x)$ 在[3,4]上单调增加，因此方程 $f(x) = 0$ 在(3,4)内有且仅有一个实根，[3,4]即为该实根的一个隔离区间.

取 $\xi_{1} = 3.5, f(3.5) = -2.625 < 0, f(4) = 9 > 0$ ，新的隔离区间为[3.5,4].

取 $\xi_{2} = 3.75, f(3.75) = 2.609 > 0, f(3.5) = -2.625 < 0$ ，又得新的隔离区间[3.5,3.75].

取 $\xi_{3} = 3.63, f(3.63) = -0.042 < 0, f(3.75) = 2.609 > 0.$ 由于 $\frac{1}{2}(3.75 - 3.63) = 0.06 < 0.1$ 则 $\xi = 3.63$ 是方程的一个近似根，其误差不超过0.1.
