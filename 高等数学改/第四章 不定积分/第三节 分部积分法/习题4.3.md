(1) $\int x^{2} \mathrm{e}^{x} \mathrm{d}x$ ;

(2) $\int (3 - x)\mathrm{e}^{-2x}\mathrm{d}x$

(3) $\int x\sin (2x + 1)\mathrm{d}x$

(4) $\int \ln^2 x\mathrm{d}x$

(5) $\int x^{2}\ln (1 + x)\mathrm{d}x$

(6) $\int \arccos x \, \mathrm{d}x$ ;

(7) $\int x\arcsin x\mathrm{d}x$

(8) $\int \mathrm{e}^{\sqrt{x}}\mathrm{d}x$

(9) $\int \arctan \sqrt{x} \mathrm{d}x$ ;

(10) $\int \frac{\ln(1 + x)}{\sqrt{x}}\mathrm{d}x$

(11) $\int x^{2} \cos^{2} x \mathrm{~d} x$

(12) $\int x\cot^2 x\mathrm{d}x$

(13) $\int \frac{x^2}{1 + x^2} \arctan x \, \mathrm{d}x$ ;

(14) $\int \frac{x\arccos x}{\sqrt{1 - x^2}}\mathrm{d}x$

(15) $\int \sin (\ln x)\mathrm{d}x$

(16) $\int (1 + 4x^{2})\mathrm{e}^{2x^{2}}\mathrm{d}x$

(17) $\int \mathrm{e}^{-2x}\sin^2 x\mathrm{d}x$

(18) $\int (\arcsin x)^2\mathrm{d}x$

(19) $\int \frac{\ln(1 + x^2)}{x^3} \, \mathrm{d}x$ ;

(20) $\int \frac{\arctan e^x}{e^{2x}} dx$ ;

(21) $\int \mathrm{e}^{-x}\frac{1 + \sin x}{1 - \cos x}\mathrm{d}x;$

(22) $\int \mathrm{e}^{2x} (\tan x + 1)^2 \, \mathrm{d}x$
