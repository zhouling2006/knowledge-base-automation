### 一、第一类换元法

定理4.2.1 若

$$
\int f (u) \mathrm {d} u = F (u) + C,
$$

且 $u = \varphi (x)$ 可导，则

$$
\int f [ \varphi (x) ] \varphi^ {\prime} (x) d x = F [ \varphi (x) ] + C. \tag {4.2.1}
$$

证 因为

$$
\int f (u) \mathrm {d} u = F (u) + C,
$$

所以 $F^{\prime}(u) = f(u)$ .根据复合函数微分法则，

$$
\frac {\mathrm {d} F [ \varphi (x) ]}{\mathrm {d} x} = F ^ {\prime} (u) \frac {\mathrm {d} u}{\mathrm {d} x} = f (u) \varphi^ {\prime} (x) = f [ \varphi (x) ] \varphi^ {\prime} (x),
$$

于是

$$
\int f [ \varphi (x) ] \varphi^ {\prime} (x) d x = F [ \varphi (x) ] + C.
$$

式（4.2.1）可以表示成

$$
\int f [ \varphi (x) ] \mathrm {d} [ \varphi (x) ] = F [ \varphi (x) ] + C. \tag {4.2.2}
$$

定理4.2.1表明，在计算 $\int g(x)\mathrm{d}x$ 时，如果能将被积表达式 $g(x)\mathrm{d}x$ 表示成 $f[\varphi (x)]\varphi '(x)\mathrm{d}x$ 的形式，则可以把该表达式中的 $\varphi^{\prime}(x)\mathrm{d}x$ 凑成 $\varphi (x)$ 的微分，即 $\varphi^{\prime}(x)\mathrm{d}x = \mathrm{d}[\varphi (x)]$ ，从而可作变换 $u = \varphi (x)$ ，将积分 $\int g(x)\mathrm{d}x$ 化成容易求的积分 $\int f(u)\mathrm{d}u$ ，即

$$
\int g (x) \mathrm {d} x = \int f [ \varphi (x) ] \varphi^ {\prime} (x) \mathrm {d} x = \int f [ \varphi (x) ] \mathrm {d} [ \varphi (x) ] = \int f (u) \mathrm {d} u | _ {u = \varphi (x)}.
$$

这里用了凑微分的方法，所以第一类换元法又称凑微分法

例4.2.2 求 $\int (1 + 3x)^{100} \mathrm{d}x$ .

解 被积函数 $(1 + 3x)^{100}$ 是由 $u^{100}$ 及 $u = 1 + 3x$ 复合而成，且 $\mathrm{d}x$ 与 $\mathrm{d}(1 + 3x)$ 仅相差一个常数因子，则

$$
(1 + 3 x) ^ {1 0 0} \mathrm {d} x = (1 + 3 x) ^ {1 0 0} \cdot \frac {1}{3} \mathrm {d} (1 + 3 x).
$$

令 $1 + 3x = u$ ，于是

$$
\int (1 + 3 x) ^ {1 0 0} \mathrm {d} x = \frac {1}{3} \int u ^ {1 0 0} \mathrm {d} u = \frac {1}{3} \cdot \frac {u ^ {1 0 1}}{1 0 1} + C = \frac {1}{3 0 3} (1 + 3 x) ^ {1 0 1} + C.
$$

运算熟练以后，我们常常不需要将 $\varphi (x)$ 记成 $u$ ，即在形式上不出现新的积分变量，而将 $\varphi (x)$ 视为一个整体直接计算.

例4.2.3 求下列不定积分：

(1) $\int \frac{\mathrm{d}x}{a^2 + x^2}$ ;

(2) $\int \frac{\mathrm{d}x}{\sqrt{a^2 - x^2}}$

(3) $\int \frac{\mathrm{d}x}{a^2 - x^2},$

其中 $a > 0$

解 (1) $\int \frac{\mathrm{d}x}{a^2 + x^2} = \frac{1}{a^2}\int \frac{\mathrm{d}x}{1 + \left(\frac{x}{a}\right)^2} = \frac{1}{a}\int \frac{\mathrm{d}\left(\frac{x}{a}\right)}{1 + \left(\frac{x}{a}\right)^2} = \frac{1}{a}\arctan \frac{x}{a} + C;$

(2) $\int \frac{\mathrm{d}x}{\sqrt{a^2 - x^2}} = \frac{1}{a}\int \frac{\mathrm{d}x}{\sqrt{1 - \left(\frac{x}{a}\right)^2}} = \int \frac{\mathrm{d}\left(\frac{x}{a}\right)}{\sqrt{1 - \left(\frac{x}{a}\right)^2}} = \arcsin \frac{x}{a} + C;$

(3) $\int \frac{\mathrm{d}x}{a^2 - x^2} = \int \frac{\mathrm{d}x}{(a + x)(a - x)} = \frac{1}{2a}\int \frac{(a - x) + (a + x)}{(a + x)(a - x)}\mathrm{d}x$

$$
\begin{array}{l} = \frac {1}{2 a} \int \left(\frac {1}{a + x} + \frac {1}{a - x}\right) d x \\ = \frac {1}{2 a} \left[ \int \frac {\mathrm {d} (a + x)}{a + x} - \int \frac {\mathrm {d} (a - x)}{a - x} \right] \\ = \frac {1}{2 a} \ln \left| \frac {a + x}{a - x} \right| + C. \\ \end{array}
$$

例4.2.4 求 $\int \frac{\mathrm{d}x}{2x^2 + 3x - 2}$

解 $\int \frac{\mathrm{d}x}{2x^2 + 3x - 2} = \int \frac{\mathrm{d}x}{(2x - 1)(x + 2)} = \frac{1}{5}\int \left(\frac{2}{2x - 1} -\frac{1}{x + 2}\right)\mathrm{d}x$

$$
\begin{array}{l} = \frac {1}{5} \left[ \int \frac {\mathrm {d} (2 x - 1)}{2 x - 1} - \int \frac {\mathrm {d} (x + 2)}{x + 2} \right] \\ = \frac {1}{5} (\ln | 2 x - 1 | - \ln | x + 2 |) + C \\ = \frac {1}{5} \ln \left| \frac {2 x - 1}{x + 2} \right| + C. \\ \end{array}
$$

在例 $4.2.2 \sim 4.2.4$ 中，我们应用了微分公式

$$
\mathrm {d} x = \frac {1}{a} \mathrm {d} (a x) = \frac {1}{a} \mathrm {d} (a x + b),
$$

其中 $a, b$ 为常数，且 $a \neq 0$ 。一般地，有

$$
\int f (a x + b) \mathrm {d} x = \frac {1}{a} \int f (a x + b) \mathrm {d} (a x + b).
$$

例4.2.5 求下列不定积分：

(1) $\int \frac{1 - 2x}{\sqrt{1 - x^2}} \, \mathrm{d}x$

(2) $\int \frac{\sin\sqrt{x}}{\sqrt{x}}\mathrm{d}x.$

解（1） $\int \frac{1 - 2x}{\sqrt{1 - x^2}}\mathrm{d}x = \int \frac{\mathrm{d}x}{\sqrt{1 - x^2}} +\int \frac{-2x}{\sqrt{1 - x^2}}\mathrm{d}x = \arcsin x + \int \frac{\mathrm{d}(-x^2)}{\sqrt{1 - x^2}}$

$$
= \arcsin x + \int \frac {\mathrm {d} (1 - x ^ {2})}{\sqrt {1 - x ^ {2}}} = \arcsin x + 2 \sqrt {1 - x ^ {2}} + C;
$$

(2) $\int \frac{\sin\sqrt{x}}{\sqrt{x}}\mathrm{d}x = 2\int \sin \sqrt{x}\mathrm{d}(\sqrt{x}) = -2\cos \sqrt{x} +C.$

例4.2.6 求 $\int \frac{\mathrm{d}x}{1 + \mathrm{e}^x}$

解 解法一 $\int \frac{\mathrm{d}x}{1 + \mathrm{e}^x} = \int \frac{1 + \mathrm{e}^x - \mathrm{e}^x}{1 + \mathrm{e}^x}\mathrm{d}x = \int \left(1 - \frac{\mathrm{e}^x}{1 + \mathrm{e}^x}\right)\mathrm{d}x$

$$
= x - \int \frac {\mathrm {d} (\mathrm {e} ^ {x} + 1)}{\mathrm {e} ^ {x} + 1} = x - \ln (1 + \mathrm {e} ^ {x}) + C.
$$

解法二 $\int \frac{\mathrm{d}x}{1 + \mathrm{e}^x} = \int \frac{\mathrm{e}^xdx}{\mathrm{e}^x(1 + \mathrm{e}^x)} = \int \left(\frac{1}{\mathrm{e}^x} -\frac{1}{1 + \mathrm{e}^x}\right)\mathrm{d}(\mathrm{e}^x)$

$$
= \ln e ^ {x} - \ln (1 + e ^ {x}) + C = x - \ln (1 + e ^ {x}) + C.
$$

例4.2.7 求 $\int \frac{\mathrm{d}x}{x(1 + \ln x)^n}$ （ $n$ 为正整数）.

解 当 $n = 1$ 时，

$$
\int \frac {\mathrm {d} x}{x (1 + \ln x) ^ {n}} = \int \frac {\mathrm {d} x}{x (1 + \ln x)} = \int \frac {\mathrm {d} (1 + \ln x)}{1 + \ln x} = \ln | 1 + \ln x | + C;
$$

当 $n\geqslant 2$ 时，

$$
\int \frac {\mathrm {d} x}{x (1 + \ln x) ^ {n}} = \int (1 + \ln x) ^ {- n} \mathrm {d} (1 + \ln x) = \frac {1}{1 - n} (1 + \ln x) ^ {1 - n} + C.
$$

例4.2.8 求 $\int x\sqrt{1 - 2x}\mathrm{d}x$

解 $\int x\sqrt{1 - 2x}\mathrm{d}x = \frac{1}{2}\int [1 - (1 - 2x)]\sqrt{1 - 2x}\mathrm{d}x = -\frac{1}{4}\int [(1 - 2x)^{\frac{1}{2}} - (1 - 2x)^{\frac{3}{2}}]\mathrm{d}(1 - 2x)$

$$
= - \frac {1}{6} (1 - 2 x) ^ {\frac {3}{2}} + \frac {1}{1 0} (1 - 2 x) ^ {\frac {5}{2}} + C = - \frac {1}{1 5} (1 + x - 6 x ^ {2}) \sqrt {1 - 2 x} + C.
$$

例4.2.9 求 $\int \tan x\mathrm{d}x$

解 $\int \tan x\mathrm{d}x = \int \frac{\sin x}{\cos x}\mathrm{d}x = -\int \frac{\mathrm{d}(\cos x)}{\cos x} = -\ln |\cos x| + C.$

同理可得

$$
\int \cot x d x = \ln | \sin x | + C.
$$

例4.2.10 求 $\int \cos^3 x\mathrm{d}x$

解 $\int \cos^3 x\mathrm{d}x = \int \cos^2 x\mathrm{d}(\sin x) = \int (1 - \sin^2 x)\mathrm{d}(\sin x) = \sin x - \frac{1}{3}\sin^3 x + C.$

同理可得

$$
\int \sin^ {3} x d x = - \cos x + \frac {1}{3} \cos^ {3} x + C.
$$

例4.2.11 求 $\int \sin^4 x\mathrm{d}x$

解 $\int \sin^4 x\mathrm{d}x = \frac{1}{4}\int (1 - \cos 2x)^2\mathrm{d}x = \frac{1}{4}\int [1 - 2\cos 2x + \cos^2 (2x)]\mathrm{d}x$

$$
\begin{array}{l} = \frac {1}{4} \int d x - \frac {1}{4} \int \cos 2 x d (2 x) + \frac {1}{8} \int (1 + \cos 4 x) d x \\ = \frac {x}{4} - \frac {1}{4} \sin 2 x + \frac {x}{8} + \frac {1}{3 2} \int \cos 4 x d (4 x) \\ = \frac {3}{8} x - \frac {1}{4} \sin 2 x + \frac {1}{3 2} \sin 4 x + C. \\ \end{array}
$$

例4.2.12 求 $\int \cos 5x\cdot \sin 3x\mathrm{d}x.$

解 $\int \cos 5x\cdot \sin 3x\mathrm{d}x = \frac{1}{2}\int (\sin 8x - \sin 2x)\mathrm{d}x$

$$
\begin{array}{l} = \frac {1}{1 6} \int \sin 8 x \mathrm {d} (8 x) - \frac {1}{4} \int \sin 2 x \mathrm {d} (2 x) \\ = - \frac {1}{1 6} \cos 8 x + \frac {1}{4} \cos 2 x + C. \\ \end{array}
$$

例4.2.13 求 $\csc x\mathrm{d}x$

解 解法一 $\int \csc x\mathrm{d}x = \int \frac{\sin x}{\sin^2x}\mathrm{d}x = \int \frac{\mathrm{d}(\cos x)}{\cos^2x - 1}$

$$
= \frac {1}{2} \ln \left| \frac {\cos x - 1}{\cos x + 1} \right| + C = \ln | \csc x - \cot x | + C.
$$

解法二 $\int \csc x\mathrm{d}x = \int \frac{(\csc x - \cot x)\csc x}{\csc x - \cot x}\mathrm{d}x = \int \frac{(-\cot x\cdot \csc x + \csc^2x)}{\csc x - \cot x}\mathrm{d}x$

$$
= \int \frac {1}{\csc x - \cot x} d (\csc x - \cot x) = \ln | \csc x - \cot x | + C.
$$

同理可得

$$
\int \sec x d x = \ln | \sec x + \tan x | + C.
$$

例4.2.14 求 $\int \tan^3 x\sec x\mathrm{d}x$

解 $\int \tan^3 x\sec x\mathrm{d}x = \int \tan^2 x\mathrm{d}(\sec x) = \int (\sec^2 x - 1)\mathrm{d}(\sec x) = \frac{1}{3}\sec^3 x - \sec x + C.$

例4.2.15 求 $\int \frac{x + 1}{x(1 + x\mathrm{e}^x)}\mathrm{d}x.$

解 $\int \frac{x + 1}{x(1 + x\mathrm{e}^x)}\mathrm{d}x = \int \frac{(x + 1)\mathrm{e}^x}{x\mathrm{e}^x(1 + x\mathrm{e}^x)}\mathrm{d}x = \int \frac{\mathrm{d}(x\mathrm{e}^x)}{x\mathrm{e}^x(1 + x\mathrm{e}^x)} = \int \left(\frac{1}{x\mathrm{e}^x} -\frac{1}{1 + x\mathrm{e}^x}\right)\mathrm{d}(x\mathrm{e}^x)$

$$
= \ln | x \mathrm {e} ^ {x} | - \ln | 1 + x \mathrm {e} ^ {x} | + C = x + \ln | x | - \ln | 1 + x \mathrm {e} ^ {x} | + C.
$$

由例 $4.2.5\sim 4.2.15$ 可知，在用第一类换元法求不定积分时，要熟悉一些常用的变换公式.例如：

$$
x \mathrm {d} x = \frac {1}{2} \mathrm {d} \left(x ^ {2}\right), \quad x ^ {2} \mathrm {d} x = \frac {1}{3} \mathrm {d} \left(x ^ {3}\right),
$$

$$
\frac {\mathrm {d} x}{\sqrt {x}} = 2 \mathrm {d} (\sqrt {x}), \quad \frac {\mathrm {d} x}{x ^ {2}} = - \mathrm {d} \left(\frac {1}{x}\right),
$$

$$
\mathrm {e} ^ {x} \mathrm {d} x = \mathrm {d} \left(\mathrm {e} ^ {x}\right), \quad \sin x \mathrm {d} x = - \mathrm {d} (\cos x),
$$

$$
\cos x \mathrm {d} x = \mathrm {d} (\sin x), \quad \sec^ {2} x \mathrm {d} x = \mathrm {d} (\tan x),
$$

$$
\csc^ {2} x \mathrm {d} x = - \mathrm {d} (\cot x), \quad \frac {\mathrm {d} x}{x} = \mathrm {d} (\ln x),
$$

$$
\sec x \cdot \tan x d x = d (\sec x), \quad \csc x \cdot \cot x d x = - d (\csc x),
$$

$$
\frac {\mathrm {d} x}{1 + x ^ {2}} = \mathrm {d} (\arctan x), \quad \frac {\mathrm {d} x}{\sqrt {1 - x ^ {2}}} = \mathrm {d} (\arcsin x).
$$
