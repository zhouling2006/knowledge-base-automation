# 第二节 换元积分法

从第四章第一节可知，使用基本积分公式和积分的线性运算法则虽然能计算一些不定积分，但能计算的不定积分是非常有限的。例如，不定积分

$$
\int \cos 2 x \mathrm {d} x, \int (1 + 3 x) ^ {1 0 0} \mathrm {d} x, \int \frac {\mathrm {d} x}{1 + \sqrt {2 x + 1}}
$$

仍无法计算. 为此, 需要进一步讨论其他的积分法则. 本节将介绍不定积分的换元积分法, 它对应微分学中复合函数的微分法则, 其在积分的计算中, 起着极其重要的作用. 换元积分法就是用一个简单的积分来代替一个相对复杂的积分, 从原始变量 $x$ 变换到新的变量 $u$ 来完成这个代换过程, 这里 $u$ 是 $x$ 的一个函数. 使用换元积分法最重要的, 也是最困难的, 就是找到这个 $u$ . 先看下面例子.

例4.2.1 求 $\int \cos 2x\mathrm{d}x$

解 基本积分表中查不到这个积分，与它相近的有公式

$$
\int \cos x d x = \sin x + C.
$$

注意到所求不定积分的被积函数是由 $\cos u$ 及 $u = 2x$ 复合而成. 若将积分变量换成 $2x$ ，则

$$
\begin{array}{l} \int \cos 2 x \mathrm {d} x = \int \cos 2 x \cdot \frac {1}{2} \mathrm {d} (2 x) = \frac {1}{2} \int \cos 2 x \mathrm {d} (2 x) \\ \xlongequal {\text {令} u = 2 x} \frac {1}{2} \int \cos u \mathrm {d} u = \frac {1}{2} \sin u + C = \frac {1}{2} \sin 2 x + C. \\ \end{array}
$$

这里所用的方法称为第一类换元积分法，简称第一类换元法。

### 一、第一类换元法

定理4.2.1 若

$$
\int f (u) \mathrm {d} u = F (u) + C,
$$

且 $u = \varphi (x)$ 可导，则

$$
\int f [ \varphi (x) ] \varphi^ {\prime} (x) d x = F [ \varphi (x) ] + C. \tag {4.2.1}
$$

证 因为

$$
\int f (u) \mathrm {d} u = F (u) + C,
$$

所以 $F^{\prime}(u) = f(u)$ .根据复合函数微分法则，

$$
\frac {\mathrm {d} F [ \varphi (x) ]}{\mathrm {d} x} = F ^ {\prime} (u) \frac {\mathrm {d} u}{\mathrm {d} x} = f (u) \varphi^ {\prime} (x) = f [ \varphi (x) ] \varphi^ {\prime} (x),
$$

于是

$$
\int f [ \varphi (x) ] \varphi^ {\prime} (x) d x = F [ \varphi (x) ] + C.
$$

式（4.2.1）可以表示成

$$
\int f [ \varphi (x) ] \mathrm {d} [ \varphi (x) ] = F [ \varphi (x) ] + C. \tag {4.2.2}
$$

定理4.2.1表明，在计算 $\int g(x)\mathrm{d}x$ 时，如果能将被积表达式 $g(x)\mathrm{d}x$ 表示成 $f[\varphi (x)]\varphi '(x)\mathrm{d}x$ 的形式，则可以把该表达式中的 $\varphi^{\prime}(x)\mathrm{d}x$ 凑成 $\varphi (x)$ 的微分，即 $\varphi^{\prime}(x)\mathrm{d}x = \mathrm{d}[\varphi (x)]$ ，从而可作变换 $u = \varphi (x)$ ，将积分 $\int g(x)\mathrm{d}x$ 化成容易求的积分 $\int f(u)\mathrm{d}u$ ，即

$$
\int g (x) \mathrm {d} x = \int f [ \varphi (x) ] \varphi^ {\prime} (x) \mathrm {d} x = \int f [ \varphi (x) ] \mathrm {d} [ \varphi (x) ] = \int f (u) \mathrm {d} u | _ {u = \varphi (x)}.
$$

这里用了凑微分的方法，所以第一类换元法又称凑微分法

例4.2.2 求 $\int (1 + 3x)^{100} \mathrm{d}x$ .

解 被积函数 $(1 + 3x)^{100}$ 是由 $u^{100}$ 及 $u = 1 + 3x$ 复合而成，且 $\mathrm{d}x$ 与 $\mathrm{d}(1 + 3x)$ 仅相差一个常数因子，则

$$
(1 + 3 x) ^ {1 0 0} \mathrm {d} x = (1 + 3 x) ^ {1 0 0} \cdot \frac {1}{3} \mathrm {d} (1 + 3 x).
$$

令 $1 + 3x = u$ ，于是

$$
\int (1 + 3 x) ^ {1 0 0} \mathrm {d} x = \frac {1}{3} \int u ^ {1 0 0} \mathrm {d} u = \frac {1}{3} \cdot \frac {u ^ {1 0 1}}{1 0 1} + C = \frac {1}{3 0 3} (1 + 3 x) ^ {1 0 1} + C.
$$

运算熟练以后，我们常常不需要将 $\varphi (x)$ 记成 $u$ ，即在形式上不出现新的积分变量，而将 $\varphi (x)$ 视为一个整体直接计算.

例4.2.3 求下列不定积分：

(1) $\int \frac{\mathrm{d}x}{a^2 + x^2}$ ;

(2) $\int \frac{\mathrm{d}x}{\sqrt{a^2 - x^2}}$

(3) $\int \frac{\mathrm{d}x}{a^2 - x^2},$

其中 $a > 0$

解 (1) $\int \frac{\mathrm{d}x}{a^2 + x^2} = \frac{1}{a^2}\int \frac{\mathrm{d}x}{1 + \left(\frac{x}{a}\right)^2} = \frac{1}{a}\int \frac{\mathrm{d}\left(\frac{x}{a}\right)}{1 + \left(\frac{x}{a}\right)^2} = \frac{1}{a}\arctan \frac{x}{a} + C;$

(2) $\int \frac{\mathrm{d}x}{\sqrt{a^2 - x^2}} = \frac{1}{a}\int \frac{\mathrm{d}x}{\sqrt{1 - \left(\frac{x}{a}\right)^2}} = \int \frac{\mathrm{d}\left(\frac{x}{a}\right)}{\sqrt{1 - \left(\frac{x}{a}\right)^2}} = \arcsin \frac{x}{a} + C;$

(3) $\int \frac{\mathrm{d}x}{a^2 - x^2} = \int \frac{\mathrm{d}x}{(a + x)(a - x)} = \frac{1}{2a}\int \frac{(a - x) + (a + x)}{(a + x)(a - x)}\mathrm{d}x$

$$
\begin{array}{l} = \frac {1}{2 a} \int \left(\frac {1}{a + x} + \frac {1}{a - x}\right) d x \\ = \frac {1}{2 a} \left[ \int \frac {\mathrm {d} (a + x)}{a + x} - \int \frac {\mathrm {d} (a - x)}{a - x} \right] \\ = \frac {1}{2 a} \ln \left| \frac {a + x}{a - x} \right| + C. \\ \end{array}
$$

例4.2.4 求 $\int \frac{\mathrm{d}x}{2x^2 + 3x - 2}$

解 $\int \frac{\mathrm{d}x}{2x^2 + 3x - 2} = \int \frac{\mathrm{d}x}{(2x - 1)(x + 2)} = \frac{1}{5}\int \left(\frac{2}{2x - 1} -\frac{1}{x + 2}\right)\mathrm{d}x$

$$
\begin{array}{l} = \frac {1}{5} \left[ \int \frac {\mathrm {d} (2 x - 1)}{2 x - 1} - \int \frac {\mathrm {d} (x + 2)}{x + 2} \right] \\ = \frac {1}{5} (\ln | 2 x - 1 | - \ln | x + 2 |) + C \\ = \frac {1}{5} \ln \left| \frac {2 x - 1}{x + 2} \right| + C. \\ \end{array}
$$

在例 $4.2.2 \sim 4.2.4$ 中，我们应用了微分公式

$$
\mathrm {d} x = \frac {1}{a} \mathrm {d} (a x) = \frac {1}{a} \mathrm {d} (a x + b),
$$

其中 $a, b$ 为常数，且 $a \neq 0$ 。一般地，有

$$
\int f (a x + b) \mathrm {d} x = \frac {1}{a} \int f (a x + b) \mathrm {d} (a x + b).
$$

例4.2.5 求下列不定积分：

(1) $\int \frac{1 - 2x}{\sqrt{1 - x^2}} \, \mathrm{d}x$

(2) $\int \frac{\sin\sqrt{x}}{\sqrt{x}}\mathrm{d}x.$

解（1） $\int \frac{1 - 2x}{\sqrt{1 - x^2}}\mathrm{d}x = \int \frac{\mathrm{d}x}{\sqrt{1 - x^2}} +\int \frac{-2x}{\sqrt{1 - x^2}}\mathrm{d}x = \arcsin x + \int \frac{\mathrm{d}(-x^2)}{\sqrt{1 - x^2}}$

$$
= \arcsin x + \int \frac {\mathrm {d} (1 - x ^ {2})}{\sqrt {1 - x ^ {2}}} = \arcsin x + 2 \sqrt {1 - x ^ {2}} + C;
$$

(2) $\int \frac{\sin\sqrt{x}}{\sqrt{x}}\mathrm{d}x = 2\int \sin \sqrt{x}\mathrm{d}(\sqrt{x}) = -2\cos \sqrt{x} +C.$

例4.2.6 求 $\int \frac{\mathrm{d}x}{1 + \mathrm{e}^x}$

解 解法一 $\int \frac{\mathrm{d}x}{1 + \mathrm{e}^x} = \int \frac{1 + \mathrm{e}^x - \mathrm{e}^x}{1 + \mathrm{e}^x}\mathrm{d}x = \int \left(1 - \frac{\mathrm{e}^x}{1 + \mathrm{e}^x}\right)\mathrm{d}x$

$$
= x - \int \frac {\mathrm {d} (\mathrm {e} ^ {x} + 1)}{\mathrm {e} ^ {x} + 1} = x - \ln (1 + \mathrm {e} ^ {x}) + C.
$$

解法二 $\int \frac{\mathrm{d}x}{1 + \mathrm{e}^x} = \int \frac{\mathrm{e}^xdx}{\mathrm{e}^x(1 + \mathrm{e}^x)} = \int \left(\frac{1}{\mathrm{e}^x} -\frac{1}{1 + \mathrm{e}^x}\right)\mathrm{d}(\mathrm{e}^x)$

$$
= \ln e ^ {x} - \ln (1 + e ^ {x}) + C = x - \ln (1 + e ^ {x}) + C.
$$

例4.2.7 求 $\int \frac{\mathrm{d}x}{x(1 + \ln x)^n}$ （ $n$ 为正整数）.

解 当 $n = 1$ 时，

$$
\int \frac {\mathrm {d} x}{x (1 + \ln x) ^ {n}} = \int \frac {\mathrm {d} x}{x (1 + \ln x)} = \int \frac {\mathrm {d} (1 + \ln x)}{1 + \ln x} = \ln | 1 + \ln x | + C;
$$

当 $n\geqslant 2$ 时，

$$
\int \frac {\mathrm {d} x}{x (1 + \ln x) ^ {n}} = \int (1 + \ln x) ^ {- n} \mathrm {d} (1 + \ln x) = \frac {1}{1 - n} (1 + \ln x) ^ {1 - n} + C.
$$

例4.2.8 求 $\int x\sqrt{1 - 2x}\mathrm{d}x$

解 $\int x\sqrt{1 - 2x}\mathrm{d}x = \frac{1}{2}\int [1 - (1 - 2x)]\sqrt{1 - 2x}\mathrm{d}x = -\frac{1}{4}\int [(1 - 2x)^{\frac{1}{2}} - (1 - 2x)^{\frac{3}{2}}]\mathrm{d}(1 - 2x)$

$$
= - \frac {1}{6} (1 - 2 x) ^ {\frac {3}{2}} + \frac {1}{1 0} (1 - 2 x) ^ {\frac {5}{2}} + C = - \frac {1}{1 5} (1 + x - 6 x ^ {2}) \sqrt {1 - 2 x} + C.
$$

例4.2.9 求 $\int \tan x\mathrm{d}x$

解 $\int \tan x\mathrm{d}x = \int \frac{\sin x}{\cos x}\mathrm{d}x = -\int \frac{\mathrm{d}(\cos x)}{\cos x} = -\ln |\cos x| + C.$

同理可得

$$
\int \cot x d x = \ln | \sin x | + C.
$$

例4.2.10 求 $\int \cos^3 x\mathrm{d}x$

解 $\int \cos^3 x\mathrm{d}x = \int \cos^2 x\mathrm{d}(\sin x) = \int (1 - \sin^2 x)\mathrm{d}(\sin x) = \sin x - \frac{1}{3}\sin^3 x + C.$

同理可得

$$
\int \sin^ {3} x d x = - \cos x + \frac {1}{3} \cos^ {3} x + C.
$$

例4.2.11 求 $\int \sin^4 x\mathrm{d}x$

解 $\int \sin^4 x\mathrm{d}x = \frac{1}{4}\int (1 - \cos 2x)^2\mathrm{d}x = \frac{1}{4}\int [1 - 2\cos 2x + \cos^2 (2x)]\mathrm{d}x$

$$
\begin{array}{l} = \frac {1}{4} \int d x - \frac {1}{4} \int \cos 2 x d (2 x) + \frac {1}{8} \int (1 + \cos 4 x) d x \\ = \frac {x}{4} - \frac {1}{4} \sin 2 x + \frac {x}{8} + \frac {1}{3 2} \int \cos 4 x d (4 x) \\ = \frac {3}{8} x - \frac {1}{4} \sin 2 x + \frac {1}{3 2} \sin 4 x + C. \\ \end{array}
$$

例4.2.12 求 $\int \cos 5x\cdot \sin 3x\mathrm{d}x.$

解 $\int \cos 5x\cdot \sin 3x\mathrm{d}x = \frac{1}{2}\int (\sin 8x - \sin 2x)\mathrm{d}x$

$$
\begin{array}{l} = \frac {1}{1 6} \int \sin 8 x \mathrm {d} (8 x) - \frac {1}{4} \int \sin 2 x \mathrm {d} (2 x) \\ = - \frac {1}{1 6} \cos 8 x + \frac {1}{4} \cos 2 x + C. \\ \end{array}
$$

例4.2.13 求 $\csc x\mathrm{d}x$

解 解法一 $\int \csc x\mathrm{d}x = \int \frac{\sin x}{\sin^2x}\mathrm{d}x = \int \frac{\mathrm{d}(\cos x)}{\cos^2x - 1}$

$$
= \frac {1}{2} \ln \left| \frac {\cos x - 1}{\cos x + 1} \right| + C = \ln | \csc x - \cot x | + C.
$$

解法二 $\int \csc x\mathrm{d}x = \int \frac{(\csc x - \cot x)\csc x}{\csc x - \cot x}\mathrm{d}x = \int \frac{(-\cot x\cdot \csc x + \csc^2x)}{\csc x - \cot x}\mathrm{d}x$

$$
= \int \frac {1}{\csc x - \cot x} d (\csc x - \cot x) = \ln | \csc x - \cot x | + C.
$$

同理可得

$$
\int \sec x d x = \ln | \sec x + \tan x | + C.
$$

例4.2.14 求 $\int \tan^3 x\sec x\mathrm{d}x$

解 $\int \tan^3 x\sec x\mathrm{d}x = \int \tan^2 x\mathrm{d}(\sec x) = \int (\sec^2 x - 1)\mathrm{d}(\sec x) = \frac{1}{3}\sec^3 x - \sec x + C.$

例4.2.15 求 $\int \frac{x + 1}{x(1 + x\mathrm{e}^x)}\mathrm{d}x.$

解 $\int \frac{x + 1}{x(1 + x\mathrm{e}^x)}\mathrm{d}x = \int \frac{(x + 1)\mathrm{e}^x}{x\mathrm{e}^x(1 + x\mathrm{e}^x)}\mathrm{d}x = \int \frac{\mathrm{d}(x\mathrm{e}^x)}{x\mathrm{e}^x(1 + x\mathrm{e}^x)} = \int \left(\frac{1}{x\mathrm{e}^x} -\frac{1}{1 + x\mathrm{e}^x}\right)\mathrm{d}(x\mathrm{e}^x)$

$$
= \ln | x \mathrm {e} ^ {x} | - \ln | 1 + x \mathrm {e} ^ {x} | + C = x + \ln | x | - \ln | 1 + x \mathrm {e} ^ {x} | + C.
$$

由例 $4.2.5\sim 4.2.15$ 可知，在用第一类换元法求不定积分时，要熟悉一些常用的变换公式.例如：

$$
x \mathrm {d} x = \frac {1}{2} \mathrm {d} \left(x ^ {2}\right), \quad x ^ {2} \mathrm {d} x = \frac {1}{3} \mathrm {d} \left(x ^ {3}\right),
$$

$$
\frac {\mathrm {d} x}{\sqrt {x}} = 2 \mathrm {d} (\sqrt {x}), \quad \frac {\mathrm {d} x}{x ^ {2}} = - \mathrm {d} \left(\frac {1}{x}\right),
$$

$$
\mathrm {e} ^ {x} \mathrm {d} x = \mathrm {d} \left(\mathrm {e} ^ {x}\right), \quad \sin x \mathrm {d} x = - \mathrm {d} (\cos x),
$$

$$
\cos x \mathrm {d} x = \mathrm {d} (\sin x), \quad \sec^ {2} x \mathrm {d} x = \mathrm {d} (\tan x),
$$

$$
\csc^ {2} x \mathrm {d} x = - \mathrm {d} (\cot x), \quad \frac {\mathrm {d} x}{x} = \mathrm {d} (\ln x),
$$

$$
\sec x \cdot \tan x d x = d (\sec x), \quad \csc x \cdot \cot x d x = - d (\csc x),
$$

$$
\frac {\mathrm {d} x}{1 + x ^ {2}} = \mathrm {d} (\arctan x), \quad \frac {\mathrm {d} x}{\sqrt {1 - x ^ {2}}} = \mathrm {d} (\arcsin x).
$$

### 二、第二类换元法

第一类换元法是把一个比较复杂的不定积分 $\int g(x)\mathrm{d}x$ 化成下列形式

$$
\int g (x) \mathrm {d} x = \int f [ \varphi (x) ] \varphi^ {\prime} (x) \mathrm {d} x = \int f [ \varphi (x) ] \mathrm {d} [ \varphi (x) ] = \int f (u) \mathrm {d} u | _ {u = \varphi (x)},
$$

然后通过不定积分的线性运算及基本积分公式或已知结论得出结果. 但有时遇到的是相反的情形, 即不定积分 $\int f(x) \mathrm{d}x$ 较难求. 这时, 作变量代换 $x = \varphi(t)$ , 有

$$
\int f (x) \mathrm {d} x = \int f [ \varphi (t) ] \varphi^ {\prime} (t) \mathrm {d} t. \tag {4.2.3}
$$

式（4.2.3）右端的不定积分比较容易计算，再将求出的不定积分中的 $t$ 以 $t = \varphi^{-1}(x)$ 代入即可。在这里，为了保证反函数 $t = \varphi^{-1}(x)$ 及积分 $\int f[\varphi(t)]\varphi(t)\mathrm{d}t$ 的存在性，假定 $x = \varphi(t)$ 是单调的可微函数， $\varphi'(t) \neq 0$ ，且 $f[\varphi(t)]\varphi'(t)$ 具有原函数，这就是第二类换元法。

定理4.2.2 设

（1） $x = \varphi (t)$ 是单调的可微函数，且 $\varphi^{\prime}(t)\neq 0$   
（2） $f[\varphi (t)]\varphi '(t)$ 具有原函数，

则

$$
\int f (x) \mathrm {d} x = \int f [ \varphi (t) ] \varphi^ {\prime} (t) \mathrm {d} t \Big | _ {t = \varphi^ {- 1} (x)}. \tag {4.2.4}
$$

证 设 $F(t)$ 是 $f[\varphi (t)]\varphi '(t)$ 的一个原函数，则

$$
\frac {\mathrm {d} F [ \varphi^ {- 1} (x) ]}{\mathrm {d} x} = F ^ {\prime} (t) [ \varphi^ {- 1} (x) ] ^ {\prime} = f [ \varphi (t) ] \varphi^ {\prime} (t) \frac {1}{\varphi^ {\prime} (t)} = f [ \varphi (t) ] = f (x).
$$

即 $F[\varphi^{-1}(x)]$ 是 $f(x)$ 的一个原函数，于是

$$
\int f (x) \mathrm {d} x = F [ \varphi^ {- 1} (x) ] + C = \int f [ \varphi (t) ] \varphi^ {\prime} (t) \mathrm {d} t \Big | _ {t = \varphi^ {- 1} (x)}.
$$

这样便证明了式（4.2.4）.

例4.2.16 求 $\int \frac{\mathrm{d}x}{1 + \sqrt{2x + 1}}$

解 计算此积分的主要困难在于被积函数中含有根式. 为了消去根式, 令 $\sqrt{2x + 1} = t$ , 即 $x = \frac{t^2 - 1}{2} (t > 0)$ , 则 $\mathrm{d}x = t\mathrm{d}t$ , 于是

$$
\begin{array}{l} \int \frac {\mathrm {d} x}{1 + \sqrt {2 x + 1}} = \int \frac {\mathrm {t d} t}{1 + t} = \int \left(1 - \frac {1}{1 + t}\right) \mathrm {d} t \\ = t - \ln | 1 + t | + C = \sqrt {2 x + 1} - \ln | 1 + \sqrt {2 x + 1} | + C. \\ \end{array}
$$

例4.2.17 求 $\int \frac{\mathrm{d}x}{\sqrt{x} + \sqrt[3]{x}}.$

解为了消去被积函数中的根式，令 $\sqrt[6]{x} = t$ ，即 $x = t^6 (t > 0)$ ，则

$$
\mathrm {d} x = 6 t ^ {5} \mathrm {d} t, \frac {1}{\sqrt {x} + \sqrt [ 3 ]{x}} = \frac {1}{t ^ {3} + t ^ {2}},
$$

于是

$$
\begin{array}{l} \int \frac {\mathrm {d} x}{\sqrt {x} + \sqrt [ 3 ]{x}} = \int \frac {6 t ^ {5}}{t ^ {3} + t ^ {2}} \mathrm {d} t = 6 \int \left(1 - t + t ^ {2} - \frac {1}{1 + t}\right) \mathrm {d} t \\ = 6 \left(t - \frac {t ^ {2}}{2} + \frac {t ^ {3}}{3} - \ln | 1 + t |\right) + C \\ = 6 \left[ \sqrt [ 6 ]{x} - \frac {\sqrt [ 3 ]{x}}{2} + \frac {\sqrt {x}}{3} - \ln (1 + \sqrt [ 6 ]{x}) \right] + C. \\ \end{array}
$$

例4.2.18 求 $\int \sqrt{a^2 - x^2}\mathrm{d}x(a > 0)$

解 利用三角恒等式 $\sin^2 t + \cos^2 t = 1$ 去掉被积函数中的根式. 不妨令

x = a \sin t \left(- \frac {\pi}{2} <   t <   \frac {\pi}{2}\right),

则 $\mathrm{dx} = a\cos t\mathrm{dt},\sqrt{a^2 - x^2} = a\cos t$ ，于是

$$
\begin{array}{l} \int \sqrt {a ^ {2} - x ^ {2}} d x = \int a ^ {2} \cos^ {2} t d t \\ = \frac {a ^ {2}}{2} \int (1 + \cos 2 t) d t \\ = \frac {a ^ {2}}{2} t + \frac {a ^ {2}}{4} \sin 2 t + C. \\ \end{array}
$$

根据变换 $x = a\sin t$ 作直角三角形（见图4.2.1），得

$$
\cos t = \frac {\sqrt {a ^ {2} - x ^ {2}}}{a},

例4.2.19 求 $\int \frac{\sqrt{x^2 + a^2}}{x^2}\mathrm{d}x(a > 0).$

解 令 $x = a \tan t\left(-\frac{\pi}{2} < t < \frac{\pi}{2}\right)$ ，则 $\mathrm{dx} = a \sec^2 t \mathrm{dt}$ ，于是

$$
\begin{array}{l} \int \frac {\sqrt {x ^ {2} + a ^ {2}}}{x ^ {2}} d x = \int \frac {a \sec t}{a ^ {2} \tan^ {2} t} \cdot a \sec^ {2} t d t = \int \frac {1}{\sin^ {2} t \cdot \cos t} d t \\ = \int \frac {\sin^ {2} t + \cos^ {2} t}{\sin^ {2} t \cdot \cos t} d t \\ = \int \sec t d t + \int \cot t \cdot \csc t d t \\ = \ln | \sec t + \tan t | - \csc t + C _ {1}. \\ \end{array}
$$

因此，

$$
\begin{array}{l} \int \frac {\sqrt {x ^ {2} + a ^ {2}}}{x ^ {2}} d x = \ln \left| \frac {\sqrt {a ^ {2} + x ^ {2}}}{a} + \frac {x}{a} \right| - \frac {\sqrt {a ^ {2} + x ^ {2}}}{x} + C _ {1} \\ = \ln \left| x + \sqrt {a ^ {2} + x ^ {2}} \right| - \frac {\sqrt {a ^ {2} + x ^ {2}}}{x} - \ln a + C _ {1} \\ = \ln \left| x + \sqrt {a ^ {2} + x ^ {2}} \right| - \frac {\sqrt {a ^ {2} + x ^ {2}}}{x} + C. \\ \end{array}
$$

这里注意到，因为 $C_1$ 是任意常数，所以 $(- \ln a + C_1)$ 仍然是任意常数，那么可记为 $C$ 。以后出现类似情形，可以同样处理。

例4.2.20 求 $\int \frac{\mathrm{d}x}{\sqrt{x^2 - a^2}} (a > 0).$

解 当 $x > a$ 时，令 $x = a \sec t\left(0 < t < \frac{\pi}{2}\right)$ ，则

$$
\mathrm {d} x = a \sec t \cdot \tan t \mathrm {d} t, \sqrt {x ^ {2} - a ^ {2}} = a \tan t,
$$

于是

$$
\begin{array}{l} \int \frac {\mathrm {d} x}{\sqrt {x ^ {2} - a ^ {2}}} = \int \frac {a \sec t \cdot \tan t}{a \tan t} \mathrm {d} t \\ = \int \sec t d t = \ln (\sec t + \tan t) + C _ {1}. \\ \end{array}
$$

由图4.2.3可知，

$$
\sec t = \frac {x}{a}, \quad \tan t = \frac {\sqrt {x ^ {2} - a ^ {2}}}{a},
$$

![](images/f393431ff1b8043c6c55b7853233066b7a4df8f9812756f94adee837708e5a6b.jpg)  
图4.2.3

则

$$
\int \frac {\mathrm {d} x}{\sqrt {x ^ {2} - a ^ {2}}} = \ln \left(\frac {x}{a} + \frac {\sqrt {x ^ {2} - a ^ {2}}}{a}\right) + C _ {1} = \ln \left(x + \sqrt {x ^ {2} - a ^ {2}}\right) + C. \tag {4.2.5}
$$

当 $x < -a$ 时，令 $x = -u$ ，则 $u > a$ ，于是由式（4.2.5）可得

$$
\begin{array}{l} \int \frac {\mathrm {d} x}{\sqrt {x ^ {2} - a ^ {2}}} = - \int \frac {\mathrm {d} u}{\sqrt {u ^ {2} - a ^ {2}}} = - \ln \left(u + \sqrt {u ^ {2} - a ^ {2}}\right) + C _ {2} = \ln \frac {1}{u + \sqrt {u ^ {2} - a ^ {2}}} + C _ {2} \\ = \ln \frac {u - \sqrt {u ^ {2} - a ^ {2}}}{a ^ {2}} + C _ {2} = \ln \left(u - \sqrt {u ^ {2} - a ^ {2}}\right) + C = \ln \left(- x - \sqrt {x ^ {2} - a ^ {2}}\right) + C. \\ \end{array}
$$

综上可得，无论 $x > a$ 或 $x < -a$ ，都有

$$
\int \frac {\mathrm {d} x}{\sqrt {x ^ {2} - a ^ {2}}} = \ln \left| x + \sqrt {x ^ {2} - a ^ {2}} \right| + C.
$$

注 从例 $4.2.18 \sim 4.2.20$ 可知，若被积函数含有根式 $\sqrt{a^2 - x^2}, \sqrt{x^2 + a^2}, \sqrt{x^2 - a^2}$ ，则可以分别令 $x = a \sin t, x = a \tan t, x = a \sec t$ 消去根式，然后再计算积分。这些代换通常称为三角代换。需要强调的是，使用三角代换计算不定积分，最后进行变量还原时，一般采用辅助直角三角形进行。

例4.2.21 求 $\int \frac{\mathrm{d}x}{x^2\sqrt{a^2 - x^2}} (a > 0).$

解 解法一 被积函数中含有根式 $\sqrt{a^2 - x^2}$ ，令 $x = a\sin t\left(-\frac{\pi}{2} < t < \frac{\pi}{2}\right)$ ，则

$$
\mathrm {d} x = a \cos t \mathrm {d} t,
$$

于是

$$
\int \frac {\mathrm {d} x}{x ^ {2} \sqrt {a ^ {2} - x ^ {2}}} = \int \frac {a \cos t \mathrm {d} t}{a ^ {2} \sin^ {2} t \cdot a \cos t} = \frac {1}{a ^ {2}} \int \csc^ {2} t \mathrm {d} t = - \frac {1}{a ^ {2}} \cot t + C = - \frac {\sqrt {a ^ {2} - x ^ {2}}}{a ^ {2} x} + C.
$$

解法二 令 $x = \frac{1}{t}$ （称之为倒代换），则 $\mathrm{dx} = -\frac{1}{t^2}\mathrm{dt}$ ，于是，当 $x > 0$ 时，

$$
\begin{array}{l} \int \frac {\mathrm {d} x}{x ^ {2} \sqrt {a ^ {2} - x ^ {2}}} = - \int \frac {t \mathrm {d} t}{\sqrt {a ^ {2} t ^ {2}} - 1} = - \frac {1}{2 a ^ {2}} \int (a ^ {2} t ^ {2} - 1) ^ {- \frac {1}{2}} \mathrm {d} (a ^ {2} t ^ {2} - 1) \\ = - \frac {1}{a ^ {2}} \sqrt {a ^ {2} t ^ {2} - 1} + C = - \frac {\sqrt {a ^ {2} - x ^ {2}}}{a ^ {2} x} + C. \\ \end{array}
$$

当 $x < 0$ 时，可得到相同结果

当被积函数是 $\frac{1}{x^2\sqrt{x^2 + a^2}}$ 或 $\frac{1}{x^2\sqrt{x^2 - a^2}}$ 时，也可作倒代换 $x = \frac{1}{t}$ 求其原函数

若被积函数含有二次根式 $\sqrt{ax^2 + bx + c}$ ( $a \neq 0$ ), 可以先将二次三项式 $ax^2 + bx + c$ 配方, 然后作三角代换.

例4.2.22 求 $\int \sqrt{-x^2 + 2x + 1}\mathrm{d}x.$

解 因为 $-x^{2} + 2x + 1 = 2 - (x - 1)^{2}$ ，所以令 $x - 1 = \sqrt{2}\sin t\left(-\frac{\pi}{2} < t < \frac{\pi}{2}\right)$ ，于是

$$
\begin{array}{l} \int \sqrt {- x ^ {2} + 2 x + 1} d x = \int \sqrt {2 - (x - 1) ^ {2}} d x = \int \sqrt {2} \cos t \cdot \sqrt {2} \cos t d t \\ = \int (1 + \cos 2 t) \mathrm {d} t = t + \frac {1}{2} \sin 2 t + C \\ = \arcsin \frac {x - 1}{\sqrt {2}} + \frac {x - 1}{2} \sqrt {- x ^ {2} + 2 x + 1} + C. \\ \end{array}
$$

例4.2.23 求 $\int \frac{2 - x}{\sqrt{2 + 2x + x^2}}\mathrm{d}x.$

解 因为 $2 + 2x + x^{2} = 1 + (x + 1)^{2}$ ，所以令 $x + 1 = \tan t\left(-\frac{\pi}{2} < t < \frac{\pi}{2}\right)$ ，于是

$$
\begin{array}{l} \int \frac {2 - x}{\sqrt {2 + 2 x + x ^ {2}}} d x = \int \frac {2 - x}{\sqrt {1 + (x + 1) ^ {2}}} d x \\ = \int \frac {3 - \tan t}{\sec t} \cdot \sec^ {2} t \mathrm {d} t \\ = 3 \int \sec t d t - \int \tan t \sec t d t \\ = 3 \ln | \tan t + \sec t | - \sec t + C \\ = 3 \ln \left| x + 1 + \sqrt {2 + 2 x + x ^ {2}} \right| - \sqrt {2 + 2 x + x ^ {2}} + C. \\ \end{array}
$$

有时，在求不定积分时，两类换元法可交替使用.

例4.2.24 求 $\int \frac{\mathrm{d}x}{x + \sqrt{1 - x^2}}$

解 令 $x = \sin t\left(-\frac{\pi}{2} < t < \frac{\pi}{2}\right)$ 则

$$
\begin{array}{l} \int \frac {\mathrm {d} x}{x + \sqrt {1 - x ^ {2}}} = \int \frac {\cos t}{\sin t + \cos t} \mathrm {d} t = \frac {1}{2} \int \frac {2 \cos t}{\sin t + \cos t} \mathrm {d} t \\ = \frac {1}{2} \int \frac {(\cos t - \sin t) + (\sin t + \cos t)}{\sin t + \cos t} d t \\ = \frac {1}{2} \int \frac {1}{\sin t + \cos t} d (\sin t + \cos t) + \frac {1}{2} \int d t \\ = \frac {1}{2} \ln | \sin t + \cos t | + \frac {1}{2} t + C \\ = \frac {1}{2} \ln \left| x + \sqrt {1 - x ^ {2}} \right| + \frac {1}{2} \arcsin x + C. \\ \end{array}
$$

例4.2.25 求 $\int \frac{x^5}{\sqrt{1 + x^2}}\mathrm{d}x.$

解 令 $x = \tan t\left(-\frac{\pi}{2} < t < \frac{\pi}{2}\right)$ 则

$$
\begin{array}{l} \int \frac {x ^ {5}}{\sqrt {1 + x ^ {2}}} d x = \int \frac {\tan^ {5} t}{\sec t} \cdot \sec^ {2} t d t = \int \tan^ {5} t \sec t d t = \int \tan^ {4} t d (\sec t) \\ = \int (\sec^ {2} t - 1) ^ {2} d (\sec t) = \int (\sec^ {4} t - 2 \sec^ {2} t + 1) d (\sec t) \\ = \frac {1}{5} \sec^ {5} t - \frac {2}{3} \sec^ {3} t + \sec t + C \\ = \frac {1}{5} \left(1 + x ^ {2}\right) ^ {\frac {5}{2}} - \frac {2}{3} \left(1 + x ^ {2}\right) ^ {\frac {3}{2}} + \left(1 + x ^ {2}\right) ^ {\frac {1}{2}} + C. \\ \end{array}
$$
