### 九、实验——函数求导及导函数画图

1. 实验目的

通过对 Mathematica 求导命令的使用，掌握导函数的性质以及它们图形之间的关系。

2. 实验内容

【基本命令】

$\mathrm{D[f[x],x]}$ ：给出 $\mathrm{f[x]}$ 对 $\mathbf{x}$ 的导函数

例2.2.42 求函数的导数 $(\sin x)'$ .

输入：

$$
D [ \sin [ x ], x ]
$$

输出：

$$
\operatorname {C o s} [ x ]
$$

例2.2.43 画出函数 $y = \mathrm{e}^{-\frac{x^2}{2}}$ 以及它的导函数的图形，并分析它们的性质. 输入：

$$
\begin{array}{l} f [ x _ {-} ] = E ^ {\wedge} (- x ^ {\wedge} 2 / 2) \\ g 1 = \operatorname {P l o t} [ f [ x ], \{x, - 4, 4 \} ] \\ \end{array}

\begin{array}{l} \text {S o l v e} [ D [ f [ x ], \{x, 2 \} ] = = 0, x ] \\ \text {S o l v e} [ D [ f [ x ], x ] = = 0, x ] \end{array}
