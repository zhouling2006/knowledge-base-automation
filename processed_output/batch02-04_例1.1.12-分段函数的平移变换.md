# 例1.1.12：分段函数的平移变换

## 题目

已知分段函数  
$$
f(x) =
\begin{cases}
x^2, & 0 \le x \le 1, \\
2x, & 1 < x \le 2,
\end{cases}
$$  
求 $f(x+1)$ 的表达式。

## 解答

函数 $f$ 是一种**对应规则**。$f(x+1)$ 表示将输入量 $x+1$ 代入该规则，即：  
> 对任意实数 $x$，先计算 $u = x+1$，再按 $f(u)$ 的分段规则输出结果。

因此需将原定义域条件中的 $x$ 替换为 $x+1$，并解出对应的新 $x$ 范围：

- 当 $0 \le x+1 \le 1$，即 $-1 \le x \le 0$，则 $f(x+1) = (x+1)^2 = x^2 + 2x + 1$；  
- 当 $1 < x+1 \le 2$，即 $0 < x \le 1$，则 $f(x+1) = 2(x+1) = 2x + 2$。

故所求函数为：
$$
f(x+1) =
\begin{cases}
x^2 + 2x + 1, & -1 \le x \le 0, \\
2x + 2, & 0 < x \le 1.
\end{cases}
$$

::: {#proof-piecewise-shift .proof label="分段平移原理" type=proof}
此变换本质是**定义域的整体平移**：原函数定义在 $[0,1] \cup (1,2]$ 上，左移1单位后变为 $[-1,0] \cup (0,1]$。各段解析式按复合函数规则 $f(x+1)$ 自动更新，无需修改函数形式本身。
:::

💡 **关键思想**：分段函数的变量替换遵循“**整体代换、同步缩放/平移定义域**”原则，是函数复合与变换的基础技能。
