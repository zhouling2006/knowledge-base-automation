# 介值定理证明

本证明通过构造辅助函数，将介值问题转化为零点存在性问题，从而调用已知的[[零点定理]]{type=concept, label=零点存在性, render=link, subject=高等数学, grade=大学, tags=连续函数|端点异号}完成推导。

::: {#proof-ivt-001 .proof label="标准证明" type=proof}
不失一般性，设 $A < B$，于是 $A < C < B$。令  
$$
F(x) = f(x) - C,\quad x \in [a,b].
$$  
由于 $f(x)$ 在 $[a,b]$ 上连续，故 $F(x)$ 也在 $[a,b]$ 上连续。又  
$$
F(a) = f(a) - C = A - C < 0, \\
F(b) = f(b) - C = B - C > 0.
$$  
由[[零点定理]]{type=concept, label=零点存在性, render=link, tags=连续函数|端点异号}可知，在 $(a,b)$ 内至少存在一点 $\xi$，使得 $F(\xi) = 0$，即  
$$
f(\xi) - C = 0 \quad \Rightarrow \quad f(\xi) = C,\quad \xi \in (a,b).
$$
:::

该证明体现了分析中典型的“转化思想”：将新命题归约为已有定理的适用场景。其逻辑闭环依赖于[[零点定理]]{type=concept}的成立，而零点定理本身又以[[最值定理引言]]{type=concept, label=实数完备性基础, render=link, tags=基础理论}为深层支撑。
