# 例1.8.11：1/x 在 (0,1] 上不一致连续

证明：函数 $f(x) = \dfrac{1}{x}$ 在 $(0,1]$ 上连续，但**不一致连续**。

::: {.example label="例1.8.11" type=example}
$f(x) = \dfrac{1}{x}$ 是初等函数，在 $(0,1]$ 上有定义且连续。

现取 $\varepsilon_0 = \dfrac{1}{2}$（或任取 $0 < \varepsilon < 1$）。假设其一致连续，则存在 $\delta > 0$，使得对任意 $x_1,x_2 \in (0,1]$，只要 $|x_1 - x_2| < \delta$，就有 $\left| \dfrac{1}{x_1} - \dfrac{1}{x_2} \right| < \varepsilon$。

取序列 $x_1^{(n)} = \dfrac{1}{n},\; x_2^{(n)} = \dfrac{1}{n+1}$，其中 $n \in \mathbb{N}^+$。显然 $x_1^{(n)}, x_2^{(n)} \in (0,1]$，且  
$$
|x_1^{(n)} - x_2^{(n)}| = \left| \frac{1}{n} - \frac{1}{n+1} \right| = \frac{1}{n(n+1)} \to 0 \quad (n \to \infty).
$$  
故对上述 $\delta$，总存在充分大的 $n$，使 $|x_1^{(n)} - x_2^{(n)}| < \delta$；但此时  
$$
\left| f(x_1^{(n)}) - f(x_2^{(n)}) \right| = \left| n - (n+1) \right| = 1 > \varepsilon_0.
$$  
矛盾。因此 $f(x) = \dfrac{1}{x}$ 在 $(0,1]$ 上**不一致连续**。
:::

该反例揭示了**区间非闭**（此处为左端点“缺失”）是导致一致连续性失效的关键——函数在趋近于 $0^+$ 时变化剧烈，无法用统一的 $\delta$ 控制所有邻域。
