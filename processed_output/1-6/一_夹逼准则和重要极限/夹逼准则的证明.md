# 夹逼准则的证明

我们使用极限的 $\varepsilon$-$\delta$ 定义进行严格证明。

**证**：任给 $\varepsilon > 0$。  
由 $\lim_{x \to x_0} g(x) = A$，存在 $\delta_1 > 0$，使得当 $0 < |x - x_0| < \delta_1$ 时，有  
$$
|g(x) - A| < \varepsilon \quad \Longrightarrow \quad A - \varepsilon < g(x) < A + \varepsilon.
$$  
同理，由 $\lim_{x \to x_0} h(x) = A$，存在 $\delta_2 > 0$，使得当 $0 < |x - x_0| < \delta_2$ 时，有  
$$
|h(x) - A| < \varepsilon \quad \Longrightarrow \quad A - \varepsilon < h(x) < A + \varepsilon.
$$  

取 $\delta = \min\{\delta_1, \delta_2, \eta\}$，则当 $0 < |x - x_0| < \delta$ 时，以下三者同时成立：  
- $A - \varepsilon < g(x) < A + \varepsilon$,  
- $A - \varepsilon < h(x) < A + \varepsilon$,  
- $g(x) \leqslant f(x) \leqslant h(x)$.  

于是可得：  
$$
A - \varepsilon < g(x) \leqslant f(x) \leqslant h(x) < A + \varepsilon,
$$  
即  
$$
|f(x) - A| < \varepsilon.
$$  

根据极限定义，$\lim_{x \to x_0} f(x) = A$。

该证明体现了 $\varepsilon$-$\delta$ 语言的核心思想：通过控制“输入偏差”来约束“输出偏差”，并借助不等式传递性完成夹逼。
