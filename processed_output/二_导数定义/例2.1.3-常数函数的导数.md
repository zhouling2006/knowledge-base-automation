# 例2.1.3：常数函数的导数

设 $f(x) = C$（其中 $C$ 为常数），求 $f'(x)$。

## 解

给自变量 $x$ 以增量 $h$，则函数增量为：

$$
f(x + h) - f(x) = C - C = 0.
$$

作差商：

$$
\frac{f(x + h) - f(x)}{h} = \frac{0}{h} = 0 \quad (h \neq 0).
$$

令 $h \to 0$ 取极限，得：

$$
f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h} = \lim_{h \to 0} 0 = 0.
$$

即：

$$
(C)' = 0.
$$

## 说明

该结果表明：**常数函数的变化率为零**，其图像为水平直线，切线斜率恒为 0，物理上对应静止状态（如位置恒定、速度为零）。
