# 函数极限的局部有界性

若 $\lim_{x \to x_0} f(x) = A$，则存在正数 $\delta$，使得 $f(x)$ 在点 $x_0$ 的去心 $\delta$ 邻域 $\mathring{U}(x_0,\delta) = \{x \mid 0 < |x - x_0| < \delta\}$ 内有界，即存在 $M > 0$，使得对所有 $x \in \mathring{U}(x_0,\delta)$，恒有 $|f(x)| \leq M$。

该性质强调“局部”二字——有界性仅在趋近点附近某个小邻域内成立，不涉及函数在更大范围（如整个区间）的行为，是函数极限区别于“整体有界函数”的关键特征。

::: {#proof-local-boundedness-001 .proof label="局部有界性证明" type=proof}
因 $\lim_{x \to x_0} f(x) = A$，取 $\varepsilon = 1$，由 $\varepsilon$-$\delta$ 定义，存在 $\delta > 0$，使得当 $0 < |x - x_0| < \delta$ 时，有  
$$
|f(x) - A| < 1.
$$  
利用三角不等式：  
$$
|f(x)| = |f(x) - A + A| \leq |f(x) - A| + |A| < 1 + |A|.
$$  
令 $M = |A| + 1$，则对所有 $x \in \mathring{U}(x_0,\delta)$，有 $|f(x)| < M$，即 $f(x)$ 在该去心邻域内有界。
:::

该证明体现了 $\varepsilon$-$\delta$ 定义中“任意小 $\varepsilon$ 可控”的威力——即使只取一个固定 $\varepsilon = 1$，已足以导出局部控制能力。
