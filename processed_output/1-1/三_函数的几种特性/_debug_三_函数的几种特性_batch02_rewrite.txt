# 例1.1.16：符号函数 sgn x 是奇函数

符号函数定义为：

$$
\operatorname{sgn} x = 
\begin{cases}
1, & x > 0, \\
0, & x = 0, \\
-1, & x < 0.
\end{cases}
$$

其定义域为 $(-\infty, +\infty)$，关于原点对称。对任意 $x \in (-\infty, +\infty)$，有：

$$
\operatorname{sgn}(-x) = 
\begin{cases}
1, & -x > 0 \iff x < 0, \\
0, & -x = 0 \iff x = 0, \\
-1, & -x < 0 \iff x > 0,
\end{cases}
= -\operatorname{sgn} x.
$$

因此，$\operatorname{sgn} x$ 满足奇函数定义。

# 例1.1.17：任意函数可分解为偶部与奇部

设 $f(x)$ 是定义在对称区间 $(-a, a)$（其中 $a > 0$）上的任意函数。定义：

- **偶部**：$F(x) = f(x) + f(-x)$  
- **奇部**：$g(x) = f(x) - f(-x)$

则：
- $F(x)$ 是 $(-a, a)$ 上的偶函数；
- $g(x)$ 是 $(-a, a)$ 上的奇函数。

**证明**：  
令 $F(x) = f(x) + f(-x)$，则对任意 $x \in (-a,a)$，
$$
F(-x) = f(-x) + f(x) = F(x),
$$
故 $F(x)$ 为偶函数。

令 $g(x) = f(x) - f(-x)$，则对任意 $x \in (-a,a)$，
$$
g(-x) = f(-x) - f(x) = -g(x),
$$
故 $g(x)$ 为奇函数。

> ✅ 推论：任一定义在对称区间上的函数，均可唯一表示为一个偶函数与一个奇函数之和：  
> $$
> f(x) = \frac{f(x)+f(-x)}{2} + \frac{f(x)-f(-x)}{2} = F_{\text{even}}(x) + g_{\text{odd}}(x).
> $$

该分解是线性空间中关于对称性的正交投影，在傅里叶分析、信号处理中具有基础地位。

参考定义：[[偶函数与奇函数的定义]]{type=concept, label=定义回顾, render=link, tags=函数性质|奇偶性}  
对比例题：[[例1.1.15-证明-f(x)-=-ln(x-+-√(x²+1))-是奇函数]]{type=question, id=例1.1.15, label=奇函数验证, render=link, tags=高数|奇函数}

::: {.example label="例1.1.17" type=example}
该例揭示了函数奇偶性的**结构性本质**：奇偶性不仅是对特定函数的分类，更是一种通用的分解工具——任何函数（只要定义域对称）都天然携带“偶成分”与“奇成分”。
:::

# 单调函数的定义

设函数 $y = f(x)$ 的定义域为 $D$，区间 $I \subseteq D$。

- 若对任意 $x_1, x_2 \in I$ 且 $x_1 < x_2$，恒有  
  $$
  f(x_1) < f(x_2) \quad \text{（或 } f(x_1) > f(x_2)\text{）},
  $$  
  则称 $f(x)$ 在 $I$ 上是**严格单调增加**（或**严格单调减少**）的；$I$ 称为**严格单调增加区间**（或**严格单调减少区间**）。

- 若将上述不等式改为  
  $f(x_1) \leqslant f(x_2)$（或 $f(x_1) \geqslant f(x_2)$），  
  则称 $f(x)$ 在 $I$ 上是**单调增加**（或**单调减少**）的。

> 📘 **教材约定**：本书中未加特别说明时，“单调函数”均指**严格单调函数**。

该定义强调：
- 单调性是**区间性质**，而非点性质；
- 必须对**区间内所有满足 $x_1 < x_2$ 的点对**成立；
- 严格单调要求不等式**严格成立**（不可取等号），这是后续导数判别法的基础前提。

关联概念：[[函数的几种特性]]{type=concept, label=函数四大特性, render=link, tags=高数|核心框架}  
前置逻辑基础：[[逻辑符号说明.md]]{type=concept, label=全称量词∀, render=link, tags=逻辑基础}

::: {.note}
注意区分：“单调”（monotonic）是广义术语，包含非严格情形；而“严格单调”（strictly monotonic）是微积分中默认使用的版本，因其与导数符号、反函数存在性等关键结论直接对应。
:::

# 单调函数的几何意义与典型例子

单调性具有直观的几何解释：

- **单调增加函数**：图像随自变量 $x$ 增大而**上升**（非下降）；  
- **单调减少函数**：图像随 $x$ 增大而**下降**（非上升）。

图1.1.17：单调增加函数示意图

![](images/dcc8c6bc912a3bfbafb07a79141cd04e480f5846aaf17cb5f0e93636ca77ffb2.jpg)  
图1.1.18：单调减少函数示意图

### 典型例子：

| 函数 | 区间 | 单调性 | 说明 |
|------|------|--------|------|
| $g(x) = x^3$ | $(-\infty, +\infty)$ | 严格单调增加 | 导数 $g'(x) = 3x^2 \geq 0$，且仅在 $x=0$ 处为零，不改变单调性 |
| $h(x) = \sin x$ | $\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$ | 严格单调增加 | 正弦在此区间内导数 $\cos x > 0$ |
| $h(x) = \sin x$ | $\left(\dfrac{\pi}{2}, \dfrac{3\pi}{2}\right)$ | 严格单调减少 | $\cos x < 0$ |
| $f(x) = x^2$ | $(0, +\infty)$ | 严格单调增加 | 对称轴右侧 |
| $f(x) = x^2$ | $(-\infty, 0)$ | 严格单调减少 | 对称轴左侧 |

> 💡 提示：一个函数可在不同子区间呈现不同单调性；判断时务必明确指定区间。
