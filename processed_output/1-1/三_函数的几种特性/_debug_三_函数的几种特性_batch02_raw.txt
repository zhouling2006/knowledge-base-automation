# 例1.1.16：符号函数 sgn x 是奇函数

符号函数定义为：

$$
\operatorname{sgn} x = 
\begin{cases}
1, & x > 0, \\
0, & x = 0, \\
-1, & x < 0.
\end{cases}
$$

该函数的定义域为 $(-\infty, +\infty)$，且关于原点对称。

::: {.example label="例1.1.16" type=example}
对任意 $x \in (-\infty, +\infty)$，有  
$$
\operatorname{sgn}(-x) = 
\begin{cases}
1, & -x > 0 \iff x < 0, \\
0, & -x = 0 \iff x = 0, \\
-1, & -x < 0 \iff x > 0,
\end{cases}
= -\operatorname{sgn} x.
$$  
因此，$\operatorname{sgn} x$ 是奇函数。
:::

该结论直接验证了奇函数定义 [[偶函数与奇函数的定义]]{type=concept, label=奇函数定义, render=link, subject=高等数学, grade=大学, tags=奇偶性|基础概念}。  
进一步理解可参考几何意义文档：[[偶函数与奇函数的典型例子及几何意义]]{type=concept, label=奇函数图像特征, render=link, tags=奇偶性|几何直观}。

# 例1.1.17：任意函数可分解为偶部与奇部

**定理（奇偶分解定理）**：设函数 $f(x)$ 定义在对称区间 $(-a, a)$（其中 $a > 0$）上，则  
- $F(x) = f(x) + f(-x)$ 是 $(-a, a)$ 上的**偶函数**；  
- $g(x) = f(x) - f(-x)$ 是 $(-a, a)$ 上的**奇函数**。  

且恒有：
$$
f(x) = \frac{1}{2}F(x) + \frac{1}{2}g(x),
$$
即任一定义在对称区间上的函数均可唯一表示为一个偶函数与一个奇函数之和。

::: {.proof label="奇偶分解证明" type=proof}
令 $F(x) = f(x) + f(-x)$，则对任意 $x \in (-a,a)$，有  
$$
F(-x) = f(-x) + f(x) = F(x),
$$  
故 $F(x)$ 为偶函数。

令 $g(x) = f(x) - f(-x)$，则  
$$
g(-x) = f(-x) - f(x) = -g(x),
$$  
故 $g(x)$ 为奇函数。
:::

该分解具有唯一性，是函数分析中的基本工具，常用于傅里叶级数、信号处理等领域。  
相关基础定义见：[[偶函数与奇函数的定义]]{type=concept, label=定义回顾, render=link, tags=奇偶性|基础概念}。  
典型应用示例见：[[例1.1.15-证明-f(x)-=-ln(x-+-√(x²+1))-是奇函数]]{type=question, id=例1.1.15, label=奇函数验证, render=card, source=教材例题, tags=奇偶性|对数函数}。

# 单调函数的定义

设函数 $y = f(x)$ 的定义域为 $D$，区间 $I \subseteq D$。

- 若对任意 $x_1, x_2 \in I$ 且 $x_1 < x_2$，恒有  
  $$
  f(x_1) < f(x_2) \quad (\text{或 } f(x_1) > f(x_2)),
  $$  
  则称 $f(x)$ 在 $I$ 上**严格单调增加**（或**严格单调减少**）；

- 若将上述不等式改为  
  $$
  f(x_1) \leqslant f(x_2) \quad (\text{或 } f(x_1) \geqslant f(x_2)),
  $$  
  则称 $f(x)$ 在 $I$ 上**单调增加**（或**单调减少**）。

> **注**：本书中“单调函数”如无特别说明，均指**严格单调函数**。

该定义强调两点核心要素：  
1. 比较必须在**同一区间** $I$ 内进行；  
2. “任意两点”的量化逻辑依赖于全称量词 $\forall$ ——参见 [[逻辑符号说明]]{type=concept, label=全称量词, render=link, tags=逻辑基础}。

单调性是后续研究函数连续性、可导性、积分性质的重要前提。

### 几何意义

### 典型实例

| 函数 | 区间 | 单调性 | 说明 |
|--------|--------|----------|------|
| $g(x) = x^3$ | $(-\infty, +\infty)$ | 严格单调增加 | 导数 $g'(x) = 3x^2 \geq 0$，仅在 $x=0$ 处为零，整体仍严格增 |
| $h(x) = \sin x$ | $\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$ | 严格单调增加 | 正弦函数在此区间内导数 $\cos x > 0$ |
| $h(x) = \sin x$ | $\left(\dfrac{\pi}{2}, \dfrac{3\pi}{2}\right)$ | 严格单调减少 | 导数 $\cos x < 0$ |
| $f(x) = x^2$ | $(0, +\infty)$ | 严格单调增加 | 对称轴右侧 |
| $f(x) = x^2$ | $(-\infty, 0)$ | 严格单调减少 | 对称轴左侧 |

这些实例印证了单调性依赖于**具体区间**——同一函数在不同区间可呈现不同单调性。
