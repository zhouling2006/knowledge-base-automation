# 全集与集合运算

在研究某一具体问题时，所考虑的所有对象构成的集合称为**全集**（或基本集），通常记作 $I$。  
设 $A, B \subseteq I$，则可定义以下四种基本集合运算：

| 运算名称 | 符号表示 | 定义（集合描述法） |
|----------|-----------|---------------------|
| **并集** | $A \cup B$ | $\{x \mid x \in A \text{ 或 } x \in B\}$ |
| **交集** | $A \cap B$ | $\{x \mid x \in A \text{ 且 } x \in B\}$ |
| **差集** | $A \setminus B$ | $\{x \mid x \in A \text{ 且 } x \notin B\}$ |
| **余集（补集）** | $\complement_I A$ 或 $I \setminus A$ | $\{x \mid x \in I \text{ 且 } x \notin A\}$ |

> 💡 **说明**：余集是相对于全集 $I$ 定义的；脱离全集谈“补集”无意义。符号 $\complement_I A$ 强调了这一依赖关系。

这些运算是集合代数的核心，满足交换律、结合律、分配律及德·摩根律（如 $\complement_I(A \cup B) = \complement_I A \cap \complement_I B$），为后续逻辑推理、测度论与拓扑学奠定基础。
