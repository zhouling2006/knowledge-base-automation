# 基本初等函数

六类函数统称为**基本初等函数**，它们是构建所有初等函数的基石：

1. **常值函数**：$y = C,\ x \in (-\infty, +\infty)$，其中 $C$ 为任意实常数  
2. **幂函数**：$y = x^{\mu}\ (\mu \in \mathbb{R})$，公共定义域为 $(0, +\infty)$  
3. **指数函数**：$y = a^{x}\ (a > 0,\ a \neq 1),\ x \in (-\infty, +\infty)$；特别地，$y = e^{x}$ 是最常用形式  
4. **对数函数**：$y = \log_{a}x\ (a > 0,\ a \neq 1),\ x \in (0, +\infty)$；其特例 $y = \ln x$ 是 $y = e^x$ 的反函数  
5. **三角函数**：包括正弦、余弦、正切、余切、正割、余割六种基本形式，统称**基本三角函数**  
6. **反三角函数**：在单调主值区间上定义的反正弦、反余弦、反正切、反余切函数，值域分别取主值范围（如 $\arcsin x \in [-\frac{\pi}{2}, \frac{\pi}{2}]$）

> ✅ **关键说明**：所有基本初等函数均具有明确解析式、典型定义域与图像特征，中学阶段已系统学习其性质与图象；大学阶段侧重其作为复合与运算基础的角色。
