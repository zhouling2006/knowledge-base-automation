# 双曲正弦函数

双曲正弦函数定义为：

$$
y = \sinh x = \frac{e^x - e^{-x}}{2}
$$

它是定义在区间 $(-\infty, +\infty)$ 上的**奇函数**，在整个实数域上**严格单调递增**，其图像通过坐标原点（见图1.1.30）。

该函数是初等函数，可由指数函数经有限次四则运算与复合构造而成，属于双曲函数族的基本成员。

参考基础函数：[[指数函数]]{type=concept, label=指数函数, render=link, subject=高等数学, grade=大学, tags=初等函数|指数函数}

延伸学习：[[双曲函数]]{type=concept, label=双曲函数总览, render=link, tags=高数|初等函数}

![](images/4db47611785130b1601f9e1ef8f0ed73ee0b816b809c69ad57be36211ea73883.jpg)  
图1.1.30

::: {.note}
双曲正弦函数常记作 $\sinh x$ 或简写为 $\mathrm{sh}\,x$，广泛应用于微分方程、物理场论与特殊函数理论中。
:::

# 双曲余弦函数

双曲余弦函数定义为：

$$
y = \cosh x = \frac{e^x + e^{-x}}{2}
$$

它是定义在区间 $(-\infty, +\infty)$ 上的**偶函数**，具有如下单调性：
- 在区间 $(-\infty, 0]$ 上**单调递减**；
- 在区间 $[0, +\infty)$ 上**单调递增**。

其图像通过点 $(0, 1)$（见图1.1.30），且满足恒等式 $\cosh^2 x - \sinh^2 x = 1$，与双曲正弦函数构成基本双曲恒等系统。

参考基础函数：[[指数函数]]{type=concept, label=指数函数, render=link, subject=高等数学, grade=大学, tags=初等函数|指数函数}

关联概念：[[双曲正弦函数]]{type=concept, label=sh x, render=link, tags=双曲函数|核心}

![](images/4db47611785130b1601f9e1ef8f0ed73ee0b816b809c69ad57be36211ea73883.jpg)  
图1.1.30

::: {.note}
双曲余弦函数常记作 $\cosh x$ 或简写为 $\mathrm{ch}\,x$；其图像称为**悬链线（catenary）**，是均匀柔性链条在重力作用下的自然形状。
:::

# 双曲正切函数

双曲正切函数定义为：

$$
y = \tanh x = \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}
$$

它是定义在区间 $(-\infty, +\infty)$ 上的**奇函数**，且在整个定义域内**严格单调递增**，值域为 $(-1, 1)$，图像通过坐标原点（见图1.1.31）。

该函数具有渐近线 $y = \pm 1$，是典型的**有界、光滑、S形（sigmoid）函数**，在神经网络激活函数、相对论速度叠加及热力学模型中有重要应用。

参考前置知识：[[双曲正弦函数]]{type=concept, label=sh x, render=link, tags=双曲函数}  
[[双曲余弦函数]]{type=concept, label=ch x, render=link, tags=双曲函数}

![](images/9559dd61333fae22095a09175b19e6a76625c6e667cc723082b2994cc713ac06.jpg)  
图1.1.31

::: {.note}
$\tanh x$ 是奇函数，满足 $\tanh(-x) = -\tanh x$；其导数为 $\tanh' x = 1 - \tanh^2 x$，体现自反馈特性。
:::

# 双曲余切函数

双曲余切函数定义为：

$$
y = \coth x = \frac{\cosh x}{\sinh x} = \frac{e^x + e^{-x}}{e^x - e^{-x}}
$$

其定义域为 $(-\infty, 0) \cup (0, +\infty)$（即全体非零实数），是**奇函数**，且在两个区间上均**严格单调递减**：
- 在 $(-\infty, 0)$ 上从 $-1^+$ 单调递减至 $-\infty$；
- 在 $(0, +\infty)$ 上从 $+\infty$ 单调递减至 $1^+$。

该函数具有垂直渐近线 $x = 0$ 和水平渐近线 $y = \pm 1$，无定义点 $x = 0$ 对应 $\sinh x = 0$。

参考关联函数：[[双曲正弦函数]]{type=concept, label=sh x, render=link, tags=双曲函数}  
[[双曲余弦函数]]{type=concept, label=ch x, render=link, tags=双曲函数}

::: {.note}
$\coth x$ 常用于电磁学中的势函数建模、流体力学中的边界层分析；注意其与三角余切 $\cot x$ 的符号习惯一致（均为奇函数、递减性相似），但定义域与行为本质不同。
:::
