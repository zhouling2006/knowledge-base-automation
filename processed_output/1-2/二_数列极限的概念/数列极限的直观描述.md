# 数列极限的直观描述

当 $n$ 无限增大时，若数列 $\{u_n\}$ 的通项 $u_n$ 能无限接近某个常数 $a$，则称该数列为**有极限的数列**（或**收敛数列**），而常数 $a$ 称为它的**极限**；否则称其**无极限**（即**发散**）。

例如：
- $\displaystyle \frac{1}{2^n} \to 0$，
- $\displaystyle \frac{n+1}{n} \to 1$，
- $\displaystyle 1 + \frac{(-1)^{n-1}}{n} \to 1$。

而以下数列不趋向于任何固定常数，故**发散**：
- $u_n = n = 1, 2, 3, \dots$（无限增大）；
- $\displaystyle u_n = \frac{1 + (-1)^{n-1}}{2} = 1, 0, 1, 0, \dots$（在 $0$ 与 $1$ 间振荡）。

这一描述体现了极限的**直观本质**：变化趋势的“终极归宿”。
