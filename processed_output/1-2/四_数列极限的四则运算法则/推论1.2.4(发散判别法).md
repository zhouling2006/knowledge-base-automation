# 推论1.2.4（发散判别法）

> **推论1.2.4**：如果数列 $\{u_n\}$ 存在**两个子数列**，它们的极限均存在但**互不相等**，则数列 $\{u_n\}$ **发散**（即极限不存在）。

形式化表述：  
若 $\exists\, \{u_{n_k}\}, \{u_{m_j}\} \subseteq \{u_n\}$，使得  
$$
\lim_{k \to \infty} u_{n_k} = L_1,\quad \lim_{j \to \infty} u_{m_j} = L_2,\quad \text{且 } L_1 \ne L_2,
$$  
则 $\lim_{n \to \infty} u_n$ 不存在。

这是**定理1.2.5的逆否命题**，是最常用、最直接的数列发散判定工具之一。

### 经典示例：$(-1)^n$ 发散  
考虑数列 $(-1)^n: -1, 1, -1, 1, \dots$：

- 奇数项子列：$u_{2k-1} = (-1)^{2k-1} = -1$，故 $\lim_{k \to \infty} u_{2k-1} = -1$；  
- 偶数项子列：$u_{2k} = (-1)^{2k} = 1$，故 $\lim_{k \to \infty} u_{2k} = 1$。

因 $-1 \ne 1$，由推论1.2.4知 $\lim_{n \to \infty} (-1)^n$ 不存在。

该方法简洁有力，避免了对 $\varepsilon$-$N$ 的复杂否定构造，是分析振荡型、分段定义型数列极限的首选策略。
