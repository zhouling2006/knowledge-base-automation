# 例1.2.7：分式乘积型数列极限

求极限  
$$
\lim_{n\to \infty}\left(\frac{5n - 1}{n}\cdot \frac{n + 4}{n}\right)
$$

**解**：  
由数列极限的乘法运算法则（定理1.2.4(2)），当两个数列极限均存在时，其乘积的极限等于极限的乘积：  
$$
\lim_{n\to \infty}\left(\frac{5n - 1}{n}\cdot \frac{n + 4}{n}\right) = \lim_{n\to \infty}\frac{5n - 1}{n}\cdot \lim_{n\to \infty}\frac{n + 4}{n}
$$

分别化简各分式：  
$$
\lim_{n\to \infty}\frac{5n - 1}{n} = \lim_{n\to \infty}\left(5 - \frac{1}{n}\right) = \lim_{n\to \infty}5 - \lim_{n\to \infty}\frac{1}{n} = 5 - 0 = 5
$$  
$$
\lim_{n\to \infty}\frac{n + 4}{n} = \lim_{n\to \infty}\left(1 + \frac{4}{n}\right) = \lim_{n\to \infty}1 + \lim_{n\to \infty}\frac{4}{n} = 1 + 0 = 1
$$

因此，  
$$
\lim_{n\to \infty}\left(\frac{5n - 1}{n}\cdot \frac{n + 4}{n}\right) = 5 \times 1 = 5
$$

该例展示了如何将复合分式乘积结构拆解为独立极限的乘积，并逐项应用常数、倒数等基本极限（如 $\lim_{n\to\infty}\frac{1}{n}=0$）。

知识点支撑：[[数列极限的四则运算法则(定理1.2.4)]]{type=concept, label=极限乘法法则, render=link, subject=高等数学, grade=大学, tags=数列极限|四则运算}  
关联方法：[[极限的运算法则]]{type=concept, label=运算法则基础, render=link, tags=高数|极限}  
延伸练习：[[例1.2.6-多项式型数列极限.md]]{type=question, id=例1.2.6, label=多项式型极限, render=card, source=教材例题, answer=1, tags=高数|数列极限|基础}

::: {.example label="例1.2.7" type=example}
求极限 $\displaystyle \lim_{n\to \infty}\left(\frac{5n - 1}{n}\cdot \frac{n + 4}{n}\right) = 5$
:::

# 例1.2.8：有理函数型数列极限（最高次幂同除法）

求极限  
$$
\lim_{n\to \infty}\frac{3n^2 - 2n + 1}{2n^2 - n + 5}
$$

**解**：  
分子分母均为关于 $n$ 的二次多项式，采用「同除最高次幂」法（即同除 $n^2$）：  
$$
\lim_{n\to \infty}\frac{3n^2 - 2n + 1}{2n^2 - n + 5} 
= \lim_{n\to \infty}\frac{3 - \frac{2}{n} + \frac{1}{n^2}}{2 - \frac{1}{n} + \frac{5}{n^2}}
$$

因分母极限非零（$\lim_{n\to\infty}\left(2 - \frac{1}{n} + \frac{5}{n^2}\right) = 2 \neq 0$），可应用商的极限法则（定理1.2.4(3)）：  
$$
= \frac{\lim_{n\to \infty}\left(3 - \frac{2}{n} + \frac{1}{n^2}\right)}{\lim_{n\to \infty}\left(2 - \frac{1}{n} + \frac{5}{n^2}\right)}
$$

再对分子分母分别应用加法与常数倍法则：  
- 分子：$\lim_{n\to \infty}3 - 2\lim_{n\to \infty}\frac{1}{n} + \left(\lim_{n\to \infty}\frac{1}{n}\right)^2 = 3 - 0 + 0 = 3$  
- 分母：$\lim_{n\to \infty}2 - \lim_{n\to \infty}\frac{1}{n} + 5\left(\lim_{n\to \infty}\frac{1}{n}\right)^2 = 2 - 0 + 0 = 2$

故原极限为  
$$
\frac{3}{2}
$$

该方法是处理「有理函数型数列极限」的标准策略，适用于分子分母为同阶或异阶多项式的情形。

核心依据：[[数列极限的四则运算法则(定理1.2.4)]]{type=concept, label=商法则适用条件, render=link, tags=数列极限|四则运算}  
对比学习：[[例1.2.6-多项式型数列极限.md]]{type=question, id=例1.2.6, label=低阶多项式极限, render=link, tags=高数|基础}  
进阶提示：若分子分母阶数不同，结果趋于 $0$ 或 $\infty$，详见 [[极限的性质]]{type=concept, label=无穷大与无穷小, render=link, tags=极限|阶分析}

::: {.example label="例1.2.8" type=example}
求极限 $\displaystyle \lim_{n\to \infty}\frac{3n^2 - 2n + 1}{2n^2 - n + 5} = \frac{3}{2}$
:::

# 例1.2.9：含根式差型极限（有理化）

求极限  
$$
\lim_{n\to \infty}n\left(\sqrt{n^2 + 1} - n\right)
$$

**解**：  
该式为 $\infty \cdot 0$ 型未定式。采用**分子有理化**消去根式差：  
$$
n\left(\sqrt{n^2 + 1} - n\right) 
= n \cdot \frac{(\sqrt{n^2 + 1} - n)(\sqrt{n^2 + 1} + n)}{\sqrt{n^2 + 1} + n}
= n \cdot \frac{(n^2 + 1) - n^2}{\sqrt{n^2 + 1} + n}
= \frac{n}{\sqrt{n^2 + 1} + n}
$$

进一步化简（分子分母同除 $n$）：  
$$
\frac{n}{\sqrt{n^2 + 1} + n} 
= \frac{1}{\sqrt{1 + \frac{1}{n^2}} + 1}
$$

由于 $\lim_{n\to \infty}\left(1 + \frac{1}{n^2}\right) = 1$，且平方根函数在 $x=1$ 处连续，由**复合函数极限性质**（见例1.2.5）得：  
$$
\lim_{n\to \infty}\sqrt{1 + \frac{1}{n^2}} = \sqrt{1} = 1
$$

因此，  
$$
\lim_{n\to \infty}\frac{1}{\sqrt{1 + \frac{1}{n^2}} + 1} 
= \frac{1}{\lim_{n\to \infty}\sqrt{1 + \frac{1}{n^2}} + \lim_{n\to \infty}1} 
= \frac{1}{1 + 1} = \frac{1}{2}
$$

本例综合运用了：有理化变形、极限四则运算、连续函数极限的代入性（复合极限），是处理“$\sqrt{n^2 + a} - n$”类问题的典型范式。

前置知识：[[数列极限的四则运算法则(定理1.2.4)]]{type=concept, label=商法则与连续性, render=link, tags=数列极限|复合函数}  
关联技巧：[[极限的性质]]{type=concept, label=连续函数极限代入, render=link, tags=极限|连续性}  
同类题型：[[例1.2.5]]{type=question, id=例1.2.5, label=根式极限基础, render=card, source=教材, tags=高数|根式}

::: {.example label="例1.2.9" type=example}
求极限 $\displaystyle \lim_{n\to \infty}n\left(\sqrt{n^2 + 1} - n\right) = \frac{1}{2}$
:::

# 例1.2.10：裂项相消型数列极限

求极限  
$$
\lim_{n\to \infty}\left[\frac{1}{1\times 2} + \frac{1}{2\times 3} + \frac{1}{3\times 4} + \dots + \frac{1}{n(n + 1)}\right]
$$

**解**：  
关键在于发现通项的**裂项恒等式**：  
$$
\frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1}, \quad \forall k \in \mathbb{N}^+
$$

于是部分和可展开为：  
$$
\begin{aligned}
&\frac{1}{1\times 2} + \frac{1}{2\times 3} + \frac{1}{3\times 4} + \dots + \frac{1}{n(n + 1)} \\
=& \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \left(\frac{1}{3} - \frac{1}{4}\right) + \dots + \left(\frac{1}{n} - \frac{1}{n + 1}\right) \\
=& 1 - \frac{1}{n + 1} \quad \text{（中间项全部抵消，呈“望远镜”状）}
\end{aligned}
$$

因此，原极限为：  
$$
\lim_{n\to \infty}\left(1 - \frac{1}{n + 1}\right) = 1 - 0 = 1
$$

此例揭示了**代数恒等变形在极限计算中的核心作用**——将复杂求和转化为可消元的简洁形式。该思想是后续学习级数收敛性（如 telescoping series）的重要起点。

理论支撑：[[数列极限的四则运算法则(定理1.2.4)]]{type=concept, label=加法法则与极限线性性, render=link, tags=数列极限|求和极限}  
延伸概念：[[极限的性质]]{type=concept, label=极限的唯一性与保号性, render=link, tags=极限|基础性质}  
实践关联：该裂项技巧亦广泛用于积分中的部分分式分解，参见 [[不定积分-有理函数分解]]{type=concept, label=有理函数积分, render=link, subject=高等数学, tags=积分|代数技巧}

求极限 $\displaystyle \lim_{n\to \infty}\sum_{k=1}^{n}\frac{1}{k(k+1)} = 1$
