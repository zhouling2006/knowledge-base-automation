# 单侧导数与可导性的关系

函数 $f(x)$ 在点 $x_0$ 处**可导**的**充要条件**是：  
> $f(x)$ 在 $x_0$ 处的左导数 $f'_-(x_0)$ 与右导数 $f'_+(x_0)$ 均存在，且相等。  

即：
$$
f'(x_0) \text{ 存在 } \iff f'_-(x_0) = f'_+(x_0) \quad (\text{且二者均为有限实数}).
$$

进一步地，若函数 $f(x)$ 在开区间 $(a,b)$ 内每一点均可导，且端点处的单侧导数存在——即右导数 $f'_+(a)$ 与左导数 $f'_-(b)$ 均存在——则称 $f(x)$ 在**闭区间 $[a,b]$ 上可导**。

该结论由函数极限与其左、右极限的关系自然导出，是判断分段函数、含绝对值函数、带根号函数等在关键点是否可导的核心判据。

::: {#thm-diff-criterion-20260405-001 .theorem label="单侧导数判别定理" type=theorem}
函数在一点可导 ⇔ 左、右导数存在且相等；  
函数在闭区间可导 ⇔ 开区间内处处可导，且两端点单侧导数存在。
:::
