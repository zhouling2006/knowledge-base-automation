# 无穷小的注释（1）

无穷小是极限为 0 的变量，不能与任何很小的固定常数混淆。

::: {.note}
这是对无穷小本质的根本性澄清：**无穷小不是“极小的数”，而是“趋于零的变量”**。它描述的是一个动态变化过程中的行为，而非静态数值大小。例如，$10^{-100}$ 是一个极小的正数，但它不随任何变量变化，因此不是无穷小；而 $x$ 当 $x \to 0$ 时是无穷小，因其取值随 $x$ 变化并无限趋近于 0。

该性质强调了无穷小的**过程依赖性**与**变量性**，是区别于初等数学中“小量估算”的关键所在。
:::
