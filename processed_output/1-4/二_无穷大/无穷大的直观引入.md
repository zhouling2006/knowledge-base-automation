# 无穷大的直观引入

当函数在某一极限过程中极限不存在，且其绝对值无限增大时，称该函数为**无穷大**。这是极限不存在情形中最重要的类型之一。

这一概念是对“函数值剧烈发散”现象的数学刻画，区别于振荡无界（如 $x\sin x$）等其他无极限行为。

相关严格定义见 [[无穷大的定义]]{type=concept, label=严格定义, render=link, subject=高等数学, grade=大学, tags=极限|无穷大|定义}。  
进一步区分方向性发散可参考 [[正无穷大与负无穷大的定义]]{type=concept, label=方向性无穷大, render=link, tags=正无穷大|负无穷大}。

::: {.note}
注意：无穷大不是数，而是一种**变量变化趋势**；它描述的是函数在特定过程中的无界增长行为，不可与“很大的数”混淆。
:::
