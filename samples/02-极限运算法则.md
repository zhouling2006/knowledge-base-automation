# 极限的运算法则

若 $\lim f(x)=A$, $\lim g(x)=B$，则：

1. $\lim (f(x) + g(x)) = A + B$
2. $\lim (f(x) g(x)) = AB$
3. 若 $B \neq 0$，则 $\lim \frac{f(x)}{g(x)} = \frac{A}{B}$

参考定义页 [[极限的定义]]{type=concept, label=回到定义, render=link, tags=极限|基础}。

例题见 [[极限综合题-例1]]{type=question, id=例1, label=分式极限题, render=card, source=高数习题, answer=2, tags=高数|极限|计算题}

::: {#proof-limit-rule-002 .proof label="分式化简过程"}
$$
\lim_{x \to +\infty} \frac{2x^2 + 3x + 1}{x^2 - 5}
=
\lim_{x \to +\infty} \frac{2 + \frac{3}{x} + \frac{1}{x^2}}{1 - \frac{5}{x^2}}
= 2
$$
:::
