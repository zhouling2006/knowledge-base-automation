### 习题3.5

1. 求下列曲线的凹凸区间及拐点：

(1) $y = 3x^4 - 4x^3 + 1$ ; 

(2) $y = \ln (1 + x^2)$ ; 

(3) $y = \frac{x}{1 + x^2}$ ; 

(4) $y = \frac{(x - 3)^2}{4(x - 1)}$ ; 

(5) $y = x^4 (12\ln x - 7)$ ; 

(6) $y = x\mathrm{e}^{2x} + 1$ . 

2. 求曲线 $x = t^2, y = 3t + t^3$ 的拐点

3. 求曲线 $x = \mathrm{e}^{t}, y = \sin t$ 的拐点

4. 证明：曲线 $y = \frac{x - 1}{x^2 + 1}$ 有三个拐点位于同一直线上

5. 问 $a, b$ 为何值时，点 $(1,3)$ 为曲线 $y = ax^3 + bx^2$ 的拐点

6. 应当怎样选择参数 $h(h > 0)$ ，使曲线 $y = \frac{h}{\sqrt{\pi}} \mathrm{e}^{-h^2 x^2}$ 在 $x = \pm a (a > 0)$ 处有拐点.

7. 描绘下列函数的图形：

(1) $y = (1 - x)\sqrt{x}$ ; 

(2) $y = \ln (1 + x^2)$ ; 

(3) $y = \frac{(x - 3)^2}{4(x - 1)}$ ; 

(4) $y = x + \frac{2x}{x^2 - 1}$ .
