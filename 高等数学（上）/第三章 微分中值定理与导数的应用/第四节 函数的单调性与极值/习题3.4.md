### 习题3.4

1. 求下列函数的单调区间：

(1) $f(x) = 3x^{4} - 4x^{3} + 1$ ; 

(2) $f(x) = \sqrt[3]{(2x - a)(a - x)^2}$ ( $a > 0$ ); 

(3) $f(x) = 2x^{2} - \ln x$ ; 

(4) $f(x) = 2\sin x + \cos 2x$ ( $0 \leqslant x \leqslant 2\pi$ )； 

(5) $f(x) = \ln (x + \sqrt{1 + x^2})$ ; 

(6) $f(x) = \frac{10}{4x^3 - 9x^2 + 6x}$ . 

2. 求下列函数的极值：

(1) $f(x) = x^{3} - 3x^{2} - 9x + 5$ ; 

(2) $f(x) = x - \ln (1 + x)$ ; 

(3) $f(x) = x^{2} \ln x$ ; 

(4) $f(x) = \mathrm{e}^{x}\cos x$ 

(5) $f(x) = 2 - (x - 1)^{\frac{2}{3}}$ ; 

(6) $f(x) = \sin x + \cos x\left(-\frac{\pi}{2} \leqslant x \leqslant \frac{\pi}{2}\right).$ 

3. 求下列函数在指定区间上的最大值和最小值：

(1) $f(x) = x^4 - 8x^2 + 2, x \in [-1,3]$ ; 

(2） $f(x) = x + 2\sqrt{x},x\in [0,4];$ 

(3) $f(x) = \sin 2x - x, x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ ; 

(4) $f(x) = \sin^3 x + \cos^3 x, x \in \left[-\frac{\pi}{4}, \frac{3\pi}{4}\right]$ ; 

(5) $f(x) = \frac{1 - x + x^2}{1 + x - x^2}, x \in [0,1]$ ; 

(6) $f(x) = \arctan \frac{1 - x}{1 + x}, x \in [0,1]$ . 

4. 证明下列不等式：

(1) $2\sqrt{x} > 3 - \frac{1}{x} (x > 1)$ ; 

(2) $1 + x \ln (x + \sqrt{1 + x^2}) > \sqrt{1 + x^2} (x > 0)$ ; 

(3) $\ln (1 + x) \geqslant \frac{\arctan x}{1 + x} (x \geqslant 0)$ ; 

(4) $\sin x + \tan x > 2x\left(0 <   x <   \frac{\pi}{2}\right);$ 

(5) $\mathrm{e}^{2x} < \frac{1 + x}{1 - x}$ (0 < x < 1); 

(6) $\arctan x + \frac{1}{x} > \frac{\pi}{2} (x > 0)$ . 

5. 证明：若 $a^2 - 3b < 0$ ，则实系数方程 $x^3 + ax^2 + bx + c = 0$ 只有唯一的实根。

6. 试问 $a$ 为何值时，函数 $f(x) = a\sin x + \frac{1}{3}\sin 3x$ 在点 $x = \frac{\pi}{3}$ 处取得极值？它是极大值还是极小值？并求此极值.

7. 设函数 $f(x)$ 在点 $x_0$ 处存在 $n$ 阶导数，且

$$
f ^ {\prime} \left(x _ {0}\right) = f ^ {\prime \prime} \left(x _ {0}\right) = f ^ {\prime \prime} \left(x _ {0}\right) = \dots = f ^ {(n - 1)} \left(x _ {0}\right) = 0, f ^ {(n)} \left(x _ {0}\right) \neq 0,
$$

试证：

（1）当 $n$ 为奇数时， $f(x)$ 在点 $x_0$ 没有极值；

(2) 当 $n$ 为偶数时, $f(x)$ 在点 $x_0$ 取得极值, 而且当 $f^{(n)}(x_0) < 0$ 时, $f(x)$ 在点 $x_0$ 取得极大值; 当 $f^{(n)}(x_0) > 0$ 时, $f(x)$ 在点 $x_0$ 取得极小值.

8. 讨论曲线 $y = 4\ln x + k$ 与曲线 $y = 4x + \ln^4 x$ 的交点个数.

9. 从一块半径为 $R$ 的圆铁片上剪去一个扇形，将剩余部分做成一个圆锥形漏斗，问剪去的扇形的圆心角多大时，才能使圆锥形漏斗的容积最大？

10. 某窗户的形状是半圆置于矩形上面所形成的。若此窗框的周长为定长，试确定半圆的半径和矩形的高，使其所通过的光线最充足。
