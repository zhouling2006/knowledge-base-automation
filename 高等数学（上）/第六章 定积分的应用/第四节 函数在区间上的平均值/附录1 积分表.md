### 附录1 积分表

1. 简单不定积分表

(1) $\int \frac{\mathrm{d}x}{ax + b} = \frac{1}{a}\ln |ax + b| + C.$ 

(2) $\int (ax + b)^{\mu} \mathrm{d}x = \frac{1}{a(\mu + 1)} (ax + b)^{\mu + 1} + C (\mu \neq -1)$ . 

(3) $\int \frac{x}{ax + b} \, \mathrm{d}x = \frac{1}{a^2} (ax + b - b \ln |ax + b|) + C.$ 

(4) $\int \frac{\mathrm{d}x}{x(ax + b)} = -\frac{1}{b}\ln \left|\frac{ax + b}{x}\right| + C.$ 

(5) $\int \sqrt{ax + b} \, \mathrm{d}x = \frac{2}{3a} \sqrt{(ax + b)^3} + C.$ 

(6) $\int x\sqrt{ax + b}\mathrm{d}x = \frac{2}{15a^2} (3ax - 2b)\sqrt{(ax + b)^3} +C.$ 

(7) $\int \frac{x}{\sqrt{ax + b}} \, \mathrm{d}x = \frac{2}{3a^2} (ax - 2b)\sqrt{ax + b} + C.$ 

(8) $\int \frac{\mathrm{d}x}{x\sqrt{ax + b}} = \left\{ \begin{array}{ll} \frac{1}{\sqrt{b}}\ln \left|\frac{\sqrt{ax + b} - \sqrt{b}}{\sqrt{ax + b} + \sqrt{b}}\right| + C & (b > 0),\\  \frac{2}{\sqrt{-b}}\arctan \sqrt{\frac{ax + b}{-b}} +C & (b <   0). \end{array} \right.$ 

(9) $\int \frac{\mathrm{d}x}{x^2 + a^2} = \frac{1}{a}\arctan \frac{x}{a} + C.$ 

(10) $\int \frac{\mathrm{d}x}{x^2 - a^2} = \frac{1}{2a}\ln \left|\frac{x - a}{x + a}\right| + C.$ 

(11) $\int \frac{x}{ax^2 + b} \, \mathrm{d}x = \frac{1}{2a} \ln |ax^2 + b| + C.$ 

(12) $\int \frac{x^2}{ax^2 + b} \, \mathrm{d}x = \frac{x}{a} - \frac{b}{a} \int \frac{\mathrm{d}x}{ax^2 + b} = \left\{ \begin{array}{l} \frac{x}{a} - \frac{b}{a\sqrt{ab}} \arctan \sqrt{\frac{a}{b}} x + c (a > 0, b > 0), \\ \frac{x}{a} - \frac{b}{2a\sqrt{-ab}} \ln \left| \frac{\sqrt{a}x - \sqrt{-b}}{\sqrt{a}x + \sqrt{-b}} \right| + C (a > 0, b < 0). \end{array} \right.$ 

(13) $\int \frac{\mathrm{d}x}{x(ax^2 + b)} = \frac{1}{2b}\ln \left|\frac{x^2}{ax^2 + b}\right| + C.$ 

(14) $\int \frac{\mathrm{d}x}{ax^2 + bx + C} = \left\{ \begin{array}{ll} \frac{2}{\sqrt{4ac - b^2}}\arctan \frac{2ax + b}{\sqrt{4ac - b^2}} + C & (a > 0, b^2 < 4ac), \\ \frac{1}{\sqrt{b^2 - 4ac}}\ln \left|\frac{2ax + b - \sqrt{b^2 - 4ac}}{2ax + b + \sqrt{b^2 - 4ac}}\right| + C & (a > 0, b^2 > 4ac). \end{array} \right.$ 

(15) $\int \frac{\mathrm{d}x}{\sqrt{x^2 + a^2}} = \ln (x + \sqrt{x^2 + a^2}) + C.$ 

(16) $\int \frac{x}{\sqrt{x^2 + a^2}} \, \mathrm{d}x = \sqrt{x^2 + a^2} + C.$ 

(17) $\int \frac{x^2}{\sqrt{x^2 + a^2}} \, \mathrm{d}x = \frac{x}{2}\sqrt{x^2 + a^2} - \frac{a^2}{2}\ln (x + \sqrt{x^2 + a^2}) + C.$ 

(18) $\int \frac{\mathrm{d}x}{x\sqrt{x^2 + a^2}} = \frac{1}{a}\ln \frac{\sqrt{x^2 + a^2} - a}{|x|} + C.$ 

(19) $\int \frac{\mathrm{d}x}{x^2\sqrt{x^2 + a^2}} = -\frac{\sqrt{x^2 + a^2}}{a^2x} + C.$ 

(20) $\int \sqrt{x^2 + a^2} \, \mathrm{d}x = \frac{x}{2} \sqrt{x^2 + a^2} + \frac{a^2}{2} \ln (x + \sqrt{x^2 + a^2}) + C.$ 

(21) $\int x\sqrt{x^2 + a^2}\mathrm{d}x = \frac{1}{3}\sqrt{(x^2 + a^2)^3} +C.$ 

(22) $\int x^{2}\sqrt{x^{2} + a^{2}}\mathrm{d}x = \frac{x}{8} (2x^{2} + a^{2})\sqrt{x^{2} + a^{2}} -\frac{a^{4}}{8}\ln (x + \sqrt{x^{2} + a^{2}}) + C.$ 

(23) $\int \frac{\mathrm{d}x}{\sqrt{x^2 - a^2}} = \ln |x + \sqrt{x^2 - a^2}| + C (a > 0).$ 

(24) $\int \frac{x}{\sqrt{x^2 - a^2}} \, \mathrm{d}x = \sqrt{x^2 - a^2} + C (a > 0)$ . 

(25) $\int \frac{x^2}{\sqrt{x^2 - a^2}} \, \mathrm{d}x = \frac{x}{2}\sqrt{x^2 - a^2} + \frac{a^2}{2}\ln |x + \sqrt{x^2 - a^2}| + C (a > 0)$ . 

(26) $\int \frac{\mathrm{d}x}{x\sqrt{x^2 - a^2}} = \frac{1}{a}\arccos \frac{a}{|x|} + C (a > 0)$ . 

(27) $\int \frac{\mathrm{d}x}{x^2\sqrt{x^2 - a^2}} = \frac{\sqrt{x^2 - a^2}}{a^2x} + C (a > 0)$ . 

(28) $\int \sqrt{x^2 - a^2} \, \mathrm{d}x = \frac{x}{2} \sqrt{x^2 - a^2} - \frac{a^2}{2} \ln |x + \sqrt{x^2 - a} - a^2| + C (a > 0)$ . 

(29) $\int x\sqrt{x^2 - a^2}\mathrm{d}x = \frac{1}{3}\sqrt{(x^2 - a^2)^3} +C(a > 0).$ 

(30) $\int x^{2}\sqrt{x^{2} - a^{2}}\mathrm{d}x = \frac{x}{8} (2x^{2} - a^{2})\sqrt{x^{2} - a^{2}} -\frac{a^{4}}{8}\ln |x + \sqrt{x^{2} - a^{2}} | + C(a > 0).$ 

(31) $\int \frac{\sqrt{x^2 - a^2}}{x} \, \mathrm{d}x = \sqrt{x^2 - a^2} - a \arccos \frac{a}{|x|} + C (a > 0)$ . 

(32) $\int \frac{\sqrt{x^2 - a^2}}{x^2} \, \mathrm{d}x = -\frac{\sqrt{x^2 - a^2}}{x} + \ln |x + \sqrt{x^2 - a^2}| + C (a > 0)$ . 

(33) $\int \frac{\mathrm{d}x}{\sqrt{a^2 - x^2}} = \arcsin \frac{x}{a} + C (a > 0)$ . 

(34) $\int \frac{x\mathrm{d}x}{\sqrt{a^2 - x^2}} = -\sqrt{a^2 - x^2} +C(a > 0).$ 

(35) $\int \frac{x^2}{\sqrt{a^2 - x^2}} \, \mathrm{d}x = -\frac{x}{2}\sqrt{a^2 - x^2} + \frac{a^2}{2}\arcsin \frac{x}{a} + C (a > 0)$ . 

(36) $\int \frac{\mathrm{d}x}{x\sqrt{a^2 - x^2}} = \frac{1}{a}\ln \frac{a - \sqrt{a^2 - x^2}}{|x|} + C (a > 0)$ . 

(37) $\int \frac{\mathrm{d}x}{x^2\sqrt{a^2 - x^2}} = -\frac{\sqrt{a^2 - x^2}}{a^2x} + C (a > 0)$ . 

(38) $\int \sqrt{a^2 - x^2} \, \mathrm{d}x = \frac{x}{2} \sqrt{a^2 - x^2} + \frac{a^2}{2} \arcsin \frac{x}{a} + C (a > 0)$ . 

(39) $\int x\sqrt{a^2 - x^2}\mathrm{d}x = -\frac{1}{3}\sqrt{(a^2 - x^2)^3} +C(a > 0).$ 

(40) $\int x^{2}\sqrt{a^{2} - x^{2}}\mathrm{d}x = \frac{x}{8} (2x^{2} - a^{2})\sqrt{a^{2} - x^{2}} +\frac{a^{4}}{8}\arcsin \frac{x}{a} +C(a > 0).$ 

(41) $\int \frac{\sqrt{a^2 - x^2}}{x} \, \mathrm{d}x = \sqrt{a^2 - x^2} + a \ln \frac{a - \sqrt{a^2 - x^2}}{|x|} + C (a > 0)$ . 

(42) $\int \frac{\sqrt{a^2 - x^2}}{x^2} \, \mathrm{d}x = -\frac{\sqrt{a^2 - x^2}}{x} - \arcsin \frac{x}{a} + C (a > 0)$ . 

（43） $\int \sin x\mathrm{d}x = -\cos x + C.$ 

（44） $\int \cos x\mathrm{d}x = \sin x + C.$ 

（45） $\int \tan x\mathrm{d}x = -\ln |\cos x| + C.$ 

（46） $\int \cot x\mathrm{d}x = \ln |\sin x| + C.$ 

(47) $\int \sec x \, \mathrm{d}x \, \mathrm{d}c = \ln |\sec x + \tan x| + C.$ 

(48) $\int \csc x \, \mathrm{d}x = \ln |\csc x - \cot x| + C.$ 

(49) $\int \sec^2 x\mathrm{d}x = \tan x + C.$ 

(50) $\int \csc^2 x\mathrm{d}x = -\cot x + C.$ 

(51) $\int \sec x \cdot \tan x \, \mathrm{d}x = \sec x + C$ . 

(52) $\int \csc x \cdot \cot x \, \mathrm{d}x = -\csc x + C.$ 

（53） $\int \sin^2 x\mathrm{d}x = \frac{x}{2} -\frac{1}{4}\sin 2x + C.$ 

（54） $\int \cos^2 x\mathrm{d}x = \frac{x}{2} +\frac{1}{4}\sin 2x + C.$ 

(55) $\int \sin ax \cdot \cos bx \, \mathrm{d}x = -\frac{1}{2(a + b)} \cos (a + b)x - \frac{1}{2(a - b)} \cos (a - b)x + C.$

(57) $\int \cos ax \cdot \cos bx \, \mathrm{d}x = \frac{1}{2(a + b)} \sin (a + b)x + \frac{1}{2(a - b)} \sin (a - b)x + C.$

2. 简单定积分表 $(m, n$ 为正整数）

（1） $\int_{-\pi}^{\pi}\cos nx\mathrm{d}x = \int_{-\pi}^{\pi}\sin nx\mathrm{d}x = 0.$ 

(2) $\int_{-\pi}^{\pi}\cos mx\cdot \sin nx\mathrm{d}x = 0.$ 

(3) $\int_{-\pi}^{\pi}\cos mx\cdot \cos nx\mathrm{d}x = \int_{-\pi}^{\pi}\sin mx\cdot \sin nx\mathrm{d}x = \left\{ \begin{array}{ll}0, & m\neq n,\\ \pi , & m = n. \end{array} \right.$ 

(4) $\int_0^\pi \cos mx\cdot \cos nx\mathrm{d}x = \int_0^\pi \sin mx\cdot \sin nx\mathrm{d}x = \left\{ \begin{array}{ll}0, & m\neq n,\\ \frac{\pi}{2}, & m = n. \end{array} \right.$ 

(5) $I_{n} = \int_{0}^{\frac{\pi}{2}}\sin^{n}x\mathrm{d}x = \int_{0}^{\frac{\pi}{2}}\cos^{n}x\mathrm{d}x = \left\{ \begin{array}{ll}\frac{(n - 1)!!}{n!!}, & n\text{为大于1的奇数,}\\ \frac{(n - 1)!!}{n!!}\cdot \frac{\pi}{2}, & n\text{为正偶数.} \end{array} \right.$ 

$$
I _ {1} = 1, I _ {0} = \frac {\pi}{2}.
$$
