### 六、实验——函数极限与间断点

1. 实验目的

通过对Mathematica计算极限命令的使用和结合函数图形，掌握函数的连续性及间断点.

2. 实验内容

【基本命令】

Limit[expr, x->x0]: 计算当 x 趋于 x0 时 expr 的极限值. Limit[expr, x->x0, Direction->1]: 计算 expr 在 x0 的左极限. Limit[expr, x->x0, Direction->-1]计算 expr 在 x0 的右极限.

ListPlot[dd，选项]：根据可选项，把数据点dd在平面上画出来

Table[a[n],{n,n0,n1,dn}]: 以 n0 为起始变量、n1 为终止变量、步长为 dn，生成一个表（或称集合）{a[n]}. Table[a[n],{n,n0,n1}]: 以 n0 为起始变量、n1 为终止变量、步长为 1，生成一个表（或称集合）{a[n]}。

例1.8.12 求两个重要极限 $\lim_{n\to +\infty}\left(1 + \frac{1}{n}\right)^n$ ， $\lim_{x\to 0}\frac{\sin x}{x}$ 

输入：

$$
\text {L i m i t} [ (1 + 1 / n) ^ {\wedge} n, n - > \text {I n f i t y} ]
$$

输出：

e 

输入：

$$
\operatorname {L i m i t} [ \sin [ x ] / x, x - > 0 ]
$$

输出：

1

例1.8.14 绘制 $y = \frac{1}{1 + \mathrm{e}^{\frac{1}{x}}}$ 和 $y = \frac{1}{1 - \mathrm{e}^{\frac{x^2}{1 - x}}}$ 的图形，观察间断点

输入：

```erlang
Limit[1/(1 + E^(1/x)), x -> 0, Direction -> 1]  
Limit[1/(1 + E^(1/x)), x -> 0, Direction -> -1] 
```

输出：

1 

0 

注 程序运行结果说明，函数在 $x = 1$ 的左、右极限分别为1和0，不相等.

输入：

$$
\operatorname {P l o t} [ 1 / (1 + E ^ {\wedge} (1 / x)), \{x, - 5, 5 \} ]
$$

输入：

```txt
Limit[1/(1 - E^x^2/(1 - x))), x -> 0]
```
