### 四、实验——定积分的计算

1. 实验目的

掌握用Mathematica求函数定积分的方法，加深理解定积分的定义中分割、近似代替、求和、取极限的思想方法.

2. 实验内容

【基本命令】

Integrae[f[x], {x, a, b}]：计算定积分 $\int_{a}^{b} f(x) \mathrm{d} x$ 。计算定积分和不定积分的命令是同一个 Integrate 函数。在计算定积分时，除了要给出变量外，还要给出积分的上、下限。当定积分算不出准确结果时，用 N[%] 命令总能得到其数值解。

NIntegrate[f[x],{x,a,b}]: 计算定积分 $\int_{a}^{b}f(x)\mathrm{d}x$ 的数值解. NIntegrate 是计算定积分的函数, 其使用方法和形式与 Integrate 函数相同. 用 Integrate 函数计算定积分得到的是准确解, 用 NIntegrate 函数计算定积分得到的是近似数值解.

$\mathrm{Sum[f[i],\{i,imin,imax\}]:}$ 计算和式 $\sum_{i = i_{\min}}^{i_{\max}}f(i)$ 

例5.6.3 计算 $\int_0^{\frac{\pi}{2}}x\sin x\mathrm{d}x$ 

输入：

Integrate[x $\star$ Sin[x], {x, 0, Pi/2}] 

输出：

1 

例5.6.4 用NIntegrate命令计算 $\int_0^1\mathrm{e}^{-x^2}\mathrm{d}x$ 的近似解

输入：

```txt
NIntegrate[E^(-x^2), {x, 0, 1}] 
```

输出：

```txt
0.746824 
```

例5.6.5 用矩形法和梯形法计算 $\int_0^1\mathrm{e}^{-x^2}\mathrm{d}x$ 的近似解

输入：

```txt
Clear[i, n]  
s1[n_]: = N[Sum[E^(-(i - 1)/n)^2)/n, {i, 1, n}]]  
s1[10]  
s1[100]  
s1[1000]  
s1[10000] 
```

输出分别为：

```csv
0.777817，0.749979，0.74714，0.746856 
```

输入：

s2[n_] $\coloneqq$ N[Sum[E^(-(2i-1)/(2n))^2)/n,{i,1,n}]]  
s2[10]  
s2[100]  
s2[1000]  
s2[10000] 

输出分别为：

```markdown
0.747131，0.746827，0746824，0746824 
```

输入：

s3[n_] $\coloneqq$ N[Sum[E^(-(i/n)^2)/n, {i, 1, n}]]  
s3[10]  
s3[100]  
s3[1000]  
s3[10000] 

输出分别为：

0.714605，0.743657，0.746508，0.746793 

输入：

```txt
s4[n_] : = N[Sum[E^(-(i/n)^2)/n, {i, 1, n-1}]] + (E^0 + E^(-1))/(2n)  
s4[10]  
s4[100]  
s4[1000]  
s4[10000] 
```

输出分别为：

0.746211，0.746818，0.746824，0.746824 

矩形法是用小矩形的面积近似代替小曲边梯形的面积，梯形法是用小直边梯形的面积近似代替小曲边梯形的面积。例5.6.5中的s1，s2和s3是在矩形法中分别用左端点、中点和右端点的函数值作为小矩形的高的计算结果，s4是梯形法的计算结果，可以看出矩形法的误差较大，梯形法的精确度较高。
