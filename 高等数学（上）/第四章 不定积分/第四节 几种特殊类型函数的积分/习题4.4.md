### 习题4.4

1. 求下列不定积分：

(1) $\int \frac{x^3 + 3x - 1}{2 + x}\mathrm{d}x$ 

(2) $\int \frac{\mathrm{d}x}{x(x - 1)^2}$ ; 

(3) $\int \frac{x + 1}{x^2 + 4x + 13} \, \mathrm{d}x$ ; 

(4) $\int \frac{\mathrm{d}x}{(1 + 2x)(1 + x^2)}$ ; 

(5) $\int \frac{3x}{(x - 1)^2(x^2 + x + 1)}\mathrm{d}x$ 

(6) $\int \frac{x^2}{(x + 2)^2(x - 1)}\mathrm{d}x$ 

(7) $\int \frac{x}{x^4 + 2x^2 + 5} \, \mathrm{d}x$ ; 

(8) $\int x\ln (x + x^3)\mathrm{d}x$ 

(9) $\int \frac{2x}{(1 + x)(1 + x^2)^2}\mathrm{d}x$ 

(10) $\int \frac{x^2}{(x^2 + 2x + 2)^2}\mathrm{d}x.$ 

2. 求下列不定积分：

(1) $\int \frac{\mathrm{d}x}{2 + \sin x}$ ; 

(2) $\int \frac{\mathrm{d}x}{4 + 5\cos x}$ ; 

(3) $\int \frac{\mathrm{d}x}{2\sin x - \cos x + 5}$ ; 

(4) $\int \frac{1 + \sin x}{\sin x(1 + \cos x)} \, \mathrm{d}x$ ; 

(5) $\int \frac{\mathrm{d}x}{\sin^3 x \cos x}$ ; 

(6) $\int \frac{\mathrm{d}x}{1 + \tan x}$ ; 

(7) $\int \frac{\mathrm{d}x}{3\sin x + 4\cos x}$ ; 

(8) $\int \frac{\sin 2x}{\sin^4 x - \cos^4 x} \, \mathrm{d}x.$ 

3. 求下列不定积分：

(1) $\int \frac{\mathrm{d}x}{2 + \sqrt[3]{1 - x}}$ ; 

(2) $\int \frac{\sqrt[3]{x}}{x(\sqrt{x} + \sqrt[3]{x})}\mathrm{d}x;$ 

(3) $\int \frac{x\mathrm{d}x}{\sqrt{x + 1} + \sqrt[3]{x + 1}}$ 

(4) $\int \frac{1}{x} \sqrt{\frac{1 + x}{1 - x}} \mathrm{d}x$ ; 

(5) $\int \frac{\sqrt{x + 1} - \sqrt{x - 1}}{\sqrt{x + 1} + \sqrt{x - 1}} \, \mathrm{d}x$ ; 

(6) $\int \frac{\mathrm{d}x}{\sqrt[3]{(x - 1)^2(x + 2)^4}};$ 

(7) $\int \frac{x}{\sqrt{1 + x - x^2}} \, \mathrm{d}x$ ; 

(8) $\int (x + 1)\sqrt{x^2 - 2x + 3}\mathrm{d}x$ 

(9) $\int \frac{\mathrm{d}x}{x^2\sqrt{2x^2 - 2x + 1}}.$ 

4. 选用适当的方法求下列不定积分：

(1) $\int \frac{x + \ln(1 - x)}{\sqrt{x}}\mathrm{d}x$ 

(2) $\int x^3\sqrt{1 + x^2}\mathrm{d}x$ 

(3) $\int \frac{\arctan x}{x^2(x^2 + 1)}\mathrm{d}x;$ 

(4) $\int \left(\frac{\ln x}{x}\right)^{2} \mathrm{d}x$ ; 

(5) $\int \frac{1 + \cos x}{1 + \sin^2 x} \, \mathrm{d}x$ ; 

(6) $\int \frac{\mathrm{d}x}{(1 + x^2)x^4}$ ; 

(7) $\int \frac{\mathrm{d}x}{x^8(1 + x^2)}$ ; 

(8) $\int \frac{x^2\arccos x}{\sqrt{1 - x^2}}\mathrm{d}x$ 

(9) $\int \ln^2 (x + \sqrt{1 + x^2})\mathrm{d}x$ 

(10) $\int \frac{x\mathrm{e}^x}{\sqrt{\mathrm{e}^x + 1}}\mathrm{d}x;$ 

(11) $\int \frac{x + \sin x}{1 + \cos x} \, \mathrm{d}x$ ; 

(12) $\int \frac{\sin^2 x}{\cos^3 x} \, \mathrm{d}x$ ; 

(13) $\int \frac{x\cos^4\frac{x}{2}}{\sin^3x}\mathrm{d}x;$ 

(14) $\int \frac{x + \sin^2 x}{(1 + x)\cos^2 x} \, \mathrm{d}x$ ; 

(15) $\int \frac{\arcsin x}{x^2} \, \mathrm{d}x$ ; 

(16) $\int \frac{\arctan x}{x^4} \mathrm{d}x$ ; 

(17) $\frac{\sin x}{\sin^3 x + \cos^3 x} \mathrm{d}x$ ; 

(18) $\int \frac{\sin x\cdot\cos x}{\sin x + \cos x}\mathrm{d}x;$ 

(19) $\int \mathrm{e}^{\sin x}\frac{x\cos^3x - \sin x}{\cos^2x}\mathrm{d}x;$ 

(20) $\int \frac{\mathrm{e}^x(1 + x\ln x)}{x}\mathrm{d}x.$
