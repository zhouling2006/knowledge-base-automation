# 常值函数

常值函数（或称**常函数**）是最简单的一类基本初等函数，其表达式为：

$$
y = C,\quad x \in (-\infty, +\infty)
$$

其中 $C$ 为任意给定实常数。

### 性质概要：
- **定义域**：全体实数 $\mathbb{R} = (-\infty, +\infty)$  
- **值域**：单点集 $\{C\}$  
- **图像**：平行于 $x$ 轴的水平直线，过点 $(0, C)$  
- **奇偶性**：既是偶函数（$f(-x) = C = f(x)$），也是奇函数（仅当 $C = 0$ 时满足 $f(-x) = -f(x)$）  
- **单调性**：在整个定义域上既不增也不减（常函数）  
- **连续性与可导性**：处处连续、处处可导，且导数恒为 $0$

> 📌 **教学提示**：常值函数是极限、导数、积分中重要的基准函数，常用于构造分段函数、验证定理边界条件（如罗尔定理中 $f(a)=f(b)$ 的情形）。

常值函数是唯一同时满足“全局最大值 = 全局最小值”的函数，也是线性函数 $y = kx + b$ 在 $k = 0$ 时的特例。
