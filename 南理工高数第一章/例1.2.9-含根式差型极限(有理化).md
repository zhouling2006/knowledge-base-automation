# 例1.2.9：含根式差型极限（有理化）

求极限  
$$
\lim_{n\to \infty}n\left(\sqrt{n^2 + 1} - n\right)
$$

**解**：  
该式为 $\infty \cdot 0$ 型未定式。采用**分子有理化**消去根式差：  
$$
n\left(\sqrt{n^2 + 1} - n\right) 
= n \cdot \frac{(\sqrt{n^2 + 1} - n)(\sqrt{n^2 + 1} + n)}{\sqrt{n^2 + 1} + n}
= n \cdot \frac{(n^2 + 1) - n^2}{\sqrt{n^2 + 1} + n}
= \frac{n}{\sqrt{n^2 + 1} + n}
$$

进一步化简（分子分母同除 $n$）：  
$$
\frac{n}{\sqrt{n^2 + 1} + n} 
= \frac{1}{\sqrt{1 + \frac{1}{n^2}} + 1}
$$

由于 $\lim_{n\to \infty}\left(1 + \frac{1}{n^2}\right) = 1$，且平方根函数在 $x=1$ 处连续，由**复合函数极限性质**（见例1.2.5）得：  
$$
\lim_{n\to \infty}\sqrt{1 + \frac{1}{n^2}} = \sqrt{1} = 1
$$

因此，  
$$
\lim_{n\to \infty}\frac{1}{\sqrt{1 + \frac{1}{n^2}} + 1} 
= \frac{1}{\lim_{n\to \infty}\sqrt{1 + \frac{1}{n^2}} + \lim_{n\to \infty}1} 
= \frac{1}{1 + 1} = \frac{1}{2}
$$

本例综合运用了：有理化变形、极限四则运算、连续函数极限的代入性（复合极限），是处理“$\sqrt{n^2 + a} - n$”类问题的典型范式。
