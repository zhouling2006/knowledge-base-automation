# 函数极限的保号性推论（极限值不等式）

若 $\lim_{x \to x_0} f(x) = A$，且在 $x_0$ 的某个去心邻域内有 $f(x) \geqslant 0$（或 $f(x) \leqslant 0$），则必有 $A \geqslant 0$（或 $A \leqslant 0$）。

该结论是函数极限**局部保号性**（[[函数极限的局部保号性]]{type=concept, label=局部保号性, render=link, subject=高等数学, grade=大学, tags=极限|核心性质}）的重要推论，常用于反证法与不等式型极限判定。

::: {#proof-theorem-1-3-6 .proof label="定理1.3.6证明" type=proof}
设 $\lim_{x \to x_0} f(x) = A$，且存在 $\delta_0 > 0$，使得当 $0 < |x - x_0| < \delta_0$ 时，恒有 $f(x) \geqslant 0$。  
假设 $A < 0$，取 $\varepsilon = -\frac{A}{2} > 0$，由极限定义，存在 $\delta_1 > 0$，使得当 $0 < |x - x_0| < \delta_1$ 时，有  
$$
|f(x) - A| < -\frac{A}{2} \quad \Rightarrow \quad f(x) < A + \left(-\frac{A}{2}\right) = \frac{A}{2} < 0,
$$  
这与 $f(x) \geqslant 0$ 矛盾。故 $A \geqslant 0$。  
同理可证 $f(x) \leqslant 0 \Rightarrow A \leqslant 0$。
:::

该推论与[[函数极限的唯一性]]{type=concept, label=极限唯一性, render=link, tags=极限|基础性质}、[[函数极限的局部有界性]]{type=concept, label=局部有界性, render=link, tags=极限|基础性质}共同构成函数极限三大基本性质，是后续研究极限运算、连续性及导数定义的逻辑基石。
