# 单调函数的几何意义与实例

### 几何意义

- **严格单调增加函数**：图像随自变量 $x$ 增大而**上升**（见图1.1.17）；  
- **严格单调减少函数**：图像随 $x$ 增大而**下降**（见图1.1.18）。

### 典型实例

| 函数 | 区间 | 单调性 | 说明 |
|--------|--------|----------|------|
| $g(x) = x^3$ | $(-\infty, +\infty)$ | 严格单调增加 | 导数 $g'(x) = 3x^2 \geq 0$，仅在 $x=0$ 处为零，整体仍严格增 |
| $h(x) = \sin x$ | $\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$ | 严格单调增加 | 正弦函数在此区间内导数 $\cos x > 0$ |
| $h(x) = \sin x$ | $\left(\dfrac{\pi}{2}, \dfrac{3\pi}{2}\right)$ | 严格单调减少 | 导数 $\cos x < 0$ |
| $f(x) = x^2$ | $(0, +\infty)$ | 严格单调增加 | 对称轴右侧 |
| $f(x) = x^2$ | $(-\infty, 0)$ | 严格单调减少 | 对称轴左侧 |

这些实例印证了单调性依赖于**具体区间**——同一函数在不同区间可呈现不同单调性。
