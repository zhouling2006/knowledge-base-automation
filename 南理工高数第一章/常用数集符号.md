# 常用数集符号

本书所用到的集合主要是**数集**（以数为元素的集合）。在未特别说明时，所有涉及的数均默认为**实数**。

以下为标准记号及其含义：

| 符号 | 名称 | 定义 |
|------|------|------|
| $\mathbf{N}$ | 自然数集 | $\{0, 1, 2, 3, \dots\}$（含 0） |
| $\mathbf{N}_+$ | 正整数集 | $\{1, 2, 3, \dots\}$ |
| $\mathbf{Z}$ | 整数集 | $\{\dots, -2, -1, 0, 1, 2, \dots\}$ |
| $\mathbf{Q}$ | 有理数集 | $\left\{ \frac{p}{q} \,\middle|\, p,q \in \mathbf{Z},\, q \ne 0 \right\}$ |
| $\mathbf{R}$ | 实数集 | 数轴上所有点对应的数的全体 |
| $\mathbf{R}_+$ | 正实数集 | $\{x \in \mathbf{R} \mid x > 0\}$ |

> 💡 **提示**：这些符号是国际通用标准，后续极限、函数、连续性等全部建立在 $\mathbf{R}$ 及其子集之上。
