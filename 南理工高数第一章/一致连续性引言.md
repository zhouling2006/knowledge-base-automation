# 一致连续性引言

函数在区间 $I$ 上连续，意味着：对任意 $x_0 \in I$，$\forall \varepsilon > 0$，$\exists \delta = \delta(\varepsilon, x_0) > 0$，使得当 $|x - x_0| < \delta$ 时，有 $|f(x) - f(x_0)| < \varepsilon$。  
此处的 $\delta$ **通常依赖于 $x_0$** —— 即使 $\varepsilon$ 固定，不同点所需的“邻域半径”可能差异显著。

而**一致连续性**刻画的是更强的整体稳定性：若存在一个仅依赖于 $\varepsilon$ 的统一 $\delta$，使得对区间 $I$ 上**任意两点** $x_1, x_2$，只要 $|x_1 - x_2| < \delta$，就有 $|f(x_1) - f(x_2)| < \varepsilon$，则称 $f$ 在 $I$ 上一致连续。

::: {.note}
这揭示了逐点连续与一致连续的本质区别：  
- 连续性是**局部、点态**性质（每个点可独立选 $\delta$）；  
- 一致连续性是**全局、均匀**性质（同一 $\delta$ 适用于全区间）。
:::

该概念为后续研究函数列一致收敛、积分定义及微分方程解的存在唯一性奠定基础。
