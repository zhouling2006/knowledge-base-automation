# 无穷小的引入与定义背景

在具有极限的函数中，极限为 0 的函数在理论上具有重要应用；为便于研究，将其称为**无穷小量**，简称**无穷小**。

这一命名并非指“非常小的数”，而是强调其**极限行为**——在特定变化过程中，函数值无限趋近于零。该概念是构建极限理论、微分学与渐近分析的基础性工具。

延伸理解：[[函数极限的定义]]{type=concept, label=极限基础, render=link, tags=高数|极限}

::: {.note}
无穷小本质上是**依赖于极限过程的变量**，脱离过程谈“无穷小”无意义。
:::
