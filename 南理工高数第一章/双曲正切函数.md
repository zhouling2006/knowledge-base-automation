# 双曲正切函数

双曲正切函数定义为：

$$
y = \tanh x = \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}
$$

它是定义在区间 $(-\infty, +\infty)$ 上的**奇函数**，且在整个定义域内**严格单调递增**，值域为 $(-1, 1)$，图像通过坐标原点（见图1.1.31）。

该函数具有渐近线 $y = \pm 1$，是典型的**有界、光滑、S形（sigmoid）函数**，在神经网络激活函数、相对论速度叠加及热力学模型中有重要应用。

::: {.note}
$\tanh x$ 是奇函数，满足 $\tanh(-x) = -\tanh x$；其导数为 $\tanh' x = 1 - \tanh^2 x$，体现自反馈特性。
:::
