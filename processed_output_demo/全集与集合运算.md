# 全集与集合运算

在特定数学问题中，我们所讨论的所有对象构成的集合称为**全集**（或基本集），记作 $I$。全集为定义集合运算提供了共同背景域。

设 $A, B \subseteq I$，定义以下四种基本运算：

| 运算名称 | 符号表示 | 定义（集合描述法） |
|----------|-----------|---------------------|
| **并集** | $A \cup B$ | $\{x \mid x \in A \text{ 或 } x \in B\}$ |
| **交集** | $A \cap B$ | $\{x \mid x \in A \text{ 且 } x \in B\}$ |
| **差集** | $A \setminus B$ | $\{x \mid x \in A \text{ 且 } x \notin B\}$ |
| **余集（补集）** | $\complement_I A$ 或 $I \setminus A$ | $\{x \mid x \in I \text{ 且 } x \notin A\}$ |

> 💡 **说明**：  
> - 差集 $A \setminus B$ 强调“属于 $A$ 但不属于 $B$”，不依赖全集；  
> - 余集 $\complement_I A$ 是差集的特例（以全集 $I$ 为被减集），其结果严格依赖于所选全集；  
> - 余集常简记为 $\complement A$（当全集 $I$ 明确时）。

这些运算是构建更复杂集合结构（如开集、闭集、σ-代数）的基石。
