# 函数的定义

设非空数集 $D \subseteq \mathbf{R}$，则称映射 $f: D \to \mathbf{R}$ 为定义在 $D$ 上的**函数**，记作  
$$
y = f(x),\quad x \in D,
$$  
其中：

- $x$ 称为**自变量**，  
- $y$ 称为**因变量**，  
- $D$ 称为**定义域**，记作 $D_f = D$，  
- 当 $x$ 取定某值 $x_0 \in D$ 时，对应的唯一值 $y_0 = f(x_0)$ 称为函数在 $x_0$ 处的**函数值**，  
- 全体函数值构成的集合称为**值域**，记作  
  $$
  R_f = \{ y \mid y = f(x),\, x \in D \}.
  $$

函数中表示对应关系的记号 $f$ 可用其他字母替代，如 $\varphi, F, g$ 等；即 $y = \varphi(x),\, y = F(x),\, y = g(x)$ 等均表示函数。

> **关键性质**：在标准函数定义中，对每个 $x \in D$，其函数值 $y$ **必须唯一**。满足此条件者称为**单值函数**。若对应法则对某些 $x$ 给出多个 $y$，则称为**多值函数**——它不直接属于本课程默认讨论对象，但可通过分解为若干**单值分支**进行研究（参见 [[多值函数与单值分支]]{type=concept, label=多值函数分解, render=link, tags=函数|隐函数}）。

::: {#note-function-elements .note label="函数的两大要素" type=note}
函数由**定义域**与**对应法则**共同决定；值域是二者自然导出的结果。二者缺一不可，且共同构成函数相等性的判定依据（详见 [[函数的两大要素与相等性]]{type=concept, label=函数相等条件, render=link, tags=函数|逻辑基础}）。
:::

# 多值函数与单值分支

在函数的标准定义中，要求对每个自变量 $x \in D$，存在**唯一确定**的因变量 $y$ 与之对应。若某对应法则对某些 $x$ 给出**多个可能的 $y$ 值**，则该法则定义了一个**多值函数**。

多值函数本身不是严格意义上的“函数”（按单值映射定义），但它在几何与物理建模中广泛存在，常以**隐式方程**形式出现。处理策略是将其分解为若干个**单值分支**（single-valued branches），每个分支均为标准函数。

## 典型示例：圆的方程

在直角坐标系中，中心在原点、半径为 $R$ 的圆满足方程：
$$
x^2 + y^2 = R^2.
$$
将其视为以 $x$ 为自变量、$y$ 为因变量的函数关系，则解得：
$$
y = \pm \sqrt{R^2 - x^2},\quad x \in [-R, R].
$$

- 当 $x = \pm R$ 时，$y = 0$（唯一）；  
- 当 $x \in (-R, R)$ 时，对每个 $x$ 存在两个实数解 $y = \sqrt{R^2 - x^2}$ 和 $y = -\sqrt{R^2 - x^2}$。  

因此，该隐式关系在 $[-R,R]$ 上定义了一个**多值函数**，其两个**单值分支**为：

- 上半圆：$y = \sqrt{R^2 - x^2},\quad x \in [-R, R]$，  
- 下半圆：$y = -\sqrt{R^2 - x^2},\quad x \in [-R, R]$。

> ✅ **注意**：今后若无特别说明，“函数”一词均指**单值函数**。多值函数仅作为分析起点，须显式指定分支后方可参与运算或绘图。

::: {#example-circle-branches .example label="圆的单值分支分解" type=example}
- 分支1（上半圆）：$y_1(x) = \sqrt{R^2 - x^2}$，连续、可导（在 $(-R,R)$ 内）；  
- 分支2（下半圆）：$y_2(x) = -\sqrt{R^2 - x^2}$，同样连续、可导（在 $(-R,R)$ 内）；  
- 在端点 $x = \pm R$ 处，两分支函数值相同（$y=0$），但导数不存在（垂直切线）。
:::

# 函数的两大要素与相等性

函数由且仅由以下**两大要素**完全确定：

1. **定义域** $D$（非空实数子集），  
2. **对应法则**（即对每个 $x \in D$，给出唯一 $y = f(x)$ 的规则）。

一旦二者给定，值域 $R_f = \{ f(x) \mid x \in D \}$ 即被**唯一确定**，故**值域不是独立要素**。

## 函数相等的充要条件

两个函数 $f$ 与 $g$ **相等**，当且仅当：

- 它们的**定义域相同**：$D(f) = D(g)$，  
- 且对**所有** $x \in D$，均有 $f(x) = g(x)$。

> ⚠️ 注意：自变量与因变量所用字母（如 $x,y$ 或 $s,t$）**不影响函数同一性**；关键在于定义域与输出值是否完全一致。

### 反例辨析

| 函数 | 定义域 | 对应法则 | 是否相等 | 原因 |
|------|--------|-----------|----------|------|
| $f(x) = \ln(x^2)$ | $(-\infty, 0) \cup (0, +\infty)$ | $x \mapsto \ln(x^2)$ | ❌ 不等 | 定义域不同 |
| $g(x) = 2\ln x$ | $(0, +\infty)$ | $x \mapsto 2\ln x$ |  | $g$ 在负数无定义，而 $f$ 有定义 |

✅ 正例：  
- $y = 3x$ 与 $s = 3t$ 表示**同一函数**：定义域均为 $\mathbb{R}$，对应法则均为“乘以3”。

::: {#proof-function-equality .proof label="相等性形式化表述" type=proof}
设 $f, g$ 为两个函数。则  
$$
f = g \iff \big( D_f = D_g \big) \land \big( \forall x \in D_f,\; f(x) = g(x) \big).
$$  
该定义排除了仅凭解析式表面相似就断言相等的常见错误（如忽略定义域限制）。
:::

# 例1.1.5：求根式分式函数的定义域

> **题目**：求函数  
> $$
> f(x) = \sqrt{\frac{(x - 1)(x - 2)}{(x - 3)(x - 4)}}
> $$  
> 的定义域。

## 解题思路

函数由解析式给出，未附加实际背景，故定义域为使表达式**有意义**的所有实数 $x$。需同时满足：

1. **分母 ≠ 0**：$(x - 3)(x - 4) \neq 0 \implies x \neq 3,\, x \neq 4$；  
2. **被开方式 ≥ 0**（偶次根号下非负）：  
   $$
   \frac{(x - 1)(x - 2)}{(x - 3)(x - 4)} \geq 0.
   $$

## 解不等式

构造符号表或使用穿针引线法解分式不等式：

临界点：$x = 1, 2, 3, 4$（分子零点：1,2；分母零点：3,4）

| 区间 | $(x-1)(x-2)$ | $(x-3)(x-4)$ | 分式符号 | 是否满足 ≥ 0 |
|------|----------------|----------------|------------|----------------|
| $(-\infty, 1)$ | $+$ | $+$ | $+$ | ✅ |
| $(1, 2)$ | $-$ | $+$ | $-$ | ❌ |
| $(2, 3)$ | $+$ | $+$ | $+$ | ✅ |
| $(3, 4)$ | $+$ | $-$ | $-$ | ❌ |
| $(4, +\infty)$ | $+$ | $+$ | $+$ | ✅ |

考虑等号成立（分子为0）：$x = 1$ 或 $x = 2$ → 分式 = 0 → 允许（根号内可为0）；  
分母为0点 $x = 3,4$ → **必须排除**。

故定义域为：  
$$
(-\infty, 1] \cup [2, 3) \cup (4, +\infty).
$$

::: {#solution-115 .solution label="答案" type=solution}
$$
\boxed{(-\infty,\, 1] \;\cup\; [2,\, 3) \;\cup\; (4,\, +\infty)}
$$
:::

# 例1.1.6：由值域反求定义域

> **题目**：已知函数  
> $$
> y = \frac{2x - 5}{x - 3}
> $$  
> 的值域为 $R_f = \{ y \mid y \leq 0 \text{ 或 } y \geq 4 \}$，求其定义域。

## 解题策略

本题为**逆问题**：已知输出范围（值域），反推输入范围（定义域）。核心是将 $y$ 的约束转化为关于 $x$ 的不等式，并注意**分母不能为0**（$x \neq 3$）。

给定：  
$$
y = \frac{2x - 5}{x - 3},\quad y \in (-\infty, 0] \cup [4, +\infty).
$$

分两部分求解：

### 情况一：$y \leq 0$

即  
$$
\frac{2x - 5}{x - 3} \leq 0.
$$  
分式 ≤ 0 ⇔ 分子分母异号（或分子=0）：

- **分子 ≥ 0 且分母 < 0**：  
  $\begin{cases} 2x - 5 \geq 0 \\ x - 3 < 0 \end{cases} \implies \begin{cases} x \geq \frac{5}{2} \\ x < 3 \end{cases} \implies \frac{5}{2} \leq x < 3$.

- **分子 ≤ 0 且分母 > 0**：  
  $\begin{cases} 2x - 5 \leq 0 \\ x - 3 > 0 \end{cases} \implies \begin{cases} x \leq \frac{5}{2} \\ x > 3 \end{cases}$ → 无解。

✅ 得：$x \in \left[\frac{5}{2},\, 3\right)$。

### 情况二：$y \geq 4$

即  
$$
\frac{2x - 5}{x - 3} \geq 4.
$$  
移项通分：  
$$
\frac{2x - 5}{x - 3} - 4 \geq 0 \iff \frac{2x - 5 - 4(x - 3)}{x - 3} \geq 0 \iff \frac{-2x + 7}{x - 3} \geq 0.
$$

同理解分式 ≥ 0：

- **分子 ≥ 0 且分母 > 0**：  
  $\begin{cases} -2x + 7 \geq 0 \\ x - 3 > 0 \end{cases} \implies \begin{cases} x \leq \frac{7}{2} \\ x > 3 \end{cases} \implies 3 < x \leq \frac{7}{2}$.

- **分子 ≤ 0 且分母 < 0**：  
  $\begin{cases} -2x + 7 \leq 0 \\ x - 3 < 0 \end{cases} \implies \begin{cases} x \geq \frac{7}{2} \\ x < 3 \end{cases}$ → 无解。

✅ 得：$x \in \left(3,\, \frac{7}{2}\right]$。

## 合并结果

注意 $x = 3$ 恒被排除（分母为0），故最终定义域为：  
$$
\left[\frac{5}{2},\, 3\right) \cup \left(3,\, \frac{7}{2}\right].
$$

::: {#solution-116 .solution label="答案" type=solution}
$$
\boxed{\left[\dfrac{5}{2},\, 3\right) \;\cup\; \left(3,\, \dfrac{7}{2}\right]}
$$
:::

延伸思考：  
- 本题凸显**值域不能唯一确定定义域**（需结合对应法则）；  
- 对比 [[例1.1.5]]{type=question, id=例1.1.5, label=正向定义域求解, render=link, tags=函数|定义域|计算题}，体现函数分析的双向性；  
- 可进一步验证：将所得定义域代入原函数，确得给定值域（略）。

# 例1.1.7：指数型函数参数拟合

> **题目**：已知函数形式为  
> $$
> f(x) = a + b \cdot c^x,
> $$  
> 且满足  
> $f(0) = 15$, $f(2) = 30$, $f(4) = 90$。  
> 求常数 $a, b, c$。

## 建立方程组

将已知点代入模型：

- $f(0) = a + b \cdot c^0 = a + b = 15$，  
- $f(2) = a + b \cdot c^2 = 30$，  
- $f(4) = a + b \cdot c^4 = 90$。

得方程组：
$$
\begin{cases}
a + b = 15 & \text{(1)}\\
a + b c^2 = 30 & \text{(2)}\\
a + b c^4 = 90 & \text{(3)}
\end{cases}
$$

## 求解步骤

**(1) 消元求 $b, c$：**  
(2) − (1)：$b(c^2 - 1) = 15$ → $b = \dfrac{15}{c^2 - 1}$ （$c^2 \ne 1$）  
(3) − (2)：$b(c^4 - c^2) = 60$ → $b c^2 (c^2 - 1) = 60$

代入 $b$：  
$$
\frac{15}{c^2 - 1} \cdot c^2 (c^2 - 1) = 60 \implies 15 c^2 = 60 \implies c^2 = 4 \implies c = \pm 2.
$$

**(2) 回代求 $a,b$：**  
- 若 $c = 2$：由 (1) $a + b = 15$；由 (2) $a + 4b = 30$ → 相减得 $3b = 15 \implies b = 5,\, a = 10$。  
- 若 $c = -2$：$c^2 = 4$ 同样满足方程，但**指数函数底数要求 $c > 0$ 且 $c \ne 1$**（否则 $c^x$ 在实数域不恒有意义，如 $(-2)^{1/2}$ 无实数解）。故舍去 $c = -2$。

✅ 得：$a = 10,\, b = 5,\, c = 2$，函数为  
$$
f(x) = 10 + 5 \cdot 2^x.
$$

::: {#solution-117 .solution label="答案" type=solution}
$$
\boxed{a = 10,\quad b = 5,\quad c = 2,\quad f(x) = 10 + 5 \cdot 2^x}
$$
:::

关键提醒：  
- 指数模型 $f(x) = a + b c^x$ 中，**$c > 0$ 是隐含前提**（确保对所有实数 $x$ 有定义）；  
- 本题体现**函数模型选择与参数约束**的重要性；  
- 关联概念：[[函数的定义]]{type=concept, label=定义域完整性, render=link, tags=函数|指数函数}（若 $c < 0$，定义域将受限于有理数分母奇偶性）。
