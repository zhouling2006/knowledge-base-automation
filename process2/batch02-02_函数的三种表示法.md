# 函数的三种表示法

函数的表示方法通常有以下三种：

1. **公式法（解析法）**：用一个或多个数学解析式明确表达对应关系，如 $f(x) = x^2 + 1$。这是高等数学研究的主要对象，便于进行极限、导数、积分等分析运算。

2. **表格法**：通过有限组输入-输出数据对列示函数关系，常见于实验测量、统计建模与离散系统建模中。

3. **图示法**：基于函数图形，以直观方式反映变量间的变化趋势与整体形态。例如，医学中心电图（ECG）即用图形表示电压 $U$ 随时间 $t$ 的连续变化（见图1.1.7）。

::: {#note-representation-001 .note label="方法互补性" type=note}
在实际应用与教学中，三者常协同使用：解析式提供精确性与可推演性；表格法支撑数值验证与插值；图示法则增强几何直觉与定性判断。高等数学虽以公式法为核心，但**图形辅助是理解抽象概念不可或缺的桥梁**。
:::
