# 例1.1.6：由值域反求定义域

> **题目**：已知函数  
> $$
> y = \frac{2x - 5}{x - 3}
> $$  
> 的值域为 $R_f = \{ y \mid y \leq 0 \text{ 或 } y \geq 4 \}$，求其定义域。

## 解题策略

本题为**逆问题**：已知输出范围（值域），反推输入范围（定义域）。核心是将 $y$ 的约束转化为关于 $x$ 的不等式，并注意**分母不能为0**（$x \neq 3$）。

给定：  
$$
y = \frac{2x - 5}{x - 3},\quad y \in (-\infty, 0] \cup [4, +\infty).
$$

分两部分求解：

### 情况一：$y \leq 0$

即  
$$
\frac{2x - 5}{x - 3} \leq 0.
$$  
分式 ≤ 0 ⇔ 分子分母异号（或分子=0）：

- **分子 ≥ 0 且分母 < 0**：  
  $\begin{cases} 2x - 5 \geq 0 \\ x - 3 < 0 \end{cases} \implies \begin{cases} x \geq \frac{5}{2} \\ x < 3 \end{cases} \implies \frac{5}{2} \leq x < 3$.

- **分子 ≤ 0 且分母 > 0**：  
  $\begin{cases} 2x - 5 \leq 0 \\ x - 3 > 0 \end{cases} \implies \begin{cases} x \leq \frac{5}{2} \\ x > 3 \end{cases}$ → 无解。

✅ 得：$x \in \left[\frac{5}{2},\, 3\right)$。

### 情况二：$y \geq 4$

即  
$$
\frac{2x - 5}{x - 3} \geq 4.
$$  
移项通分：  
$$
\frac{2x - 5}{x - 3} - 4 \geq 0 \iff \frac{2x - 5 - 4(x - 3)}{x - 3} \geq 0 \iff \frac{-2x + 7}{x - 3} \geq 0.
$$

同理解分式 ≥ 0：

- **分子 ≥ 0 且分母 > 0**：  
  $\begin{cases} -2x + 7 \geq 0 \\ x - 3 > 0 \end{cases} \implies \begin{cases} x \leq \frac{7}{2} \\ x > 3 \end{cases} \implies 3 < x \leq \frac{7}{2}$.

- **分子 ≤ 0 且分母 < 0**：  
  $\begin{cases} -2x + 7 \leq 0 \\ x - 3 < 0 \end{cases} \implies \begin{cases} x \geq \frac{7}{2} \\ x < 3 \end{cases}$ → 无解。

✅ 得：$x \in \left(3,\, \frac{7}{2}\right]$。

## 合并结果

注意 $x = 3$ 恒被排除（分母为0），故最终定义域为：  
$$
\left[\frac{5}{2},\, 3\right) \cup \left(3,\, \frac{7}{2}\right].
$$

::: {#solution-116 .solution label="答案" type=solution}
$$
\boxed{\left[\dfrac{5}{2},\, 3\right) \;\cup\; \left(3,\, \dfrac{7}{2}\right]}
$$
:::
