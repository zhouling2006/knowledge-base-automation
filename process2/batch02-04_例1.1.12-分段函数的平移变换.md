# 例1.1.12：分段函数的平移变换

> **题目**：设  
> $$
f(x) =
\begin{cases}
x^2, & 0 \leq x \leq 1, \\
2x, & 1 < x \leq 2,
\end{cases}
$$  
> 求 $f(x+1)$ 的表示式。

::: {#sol-1112-001 .solution label="解法步骤" type=solution}
函数 $f$ 是一种**对应规则**；$f(x+1)$ 表示将输入量整体替换为 $(x+1)$ 后，按原规则执行运算。因此需将原定义域中每一段的不等式条件中的 $x$ 替换为 $(x+1)$，再解出新变量 $x$ 的范围：

- 当 $0 \leq x+1 \leq 1$，即 $-1 \leq x \leq 0$，得 $(x+1)^2 = x^2 + 2x + 1$；
- 当 $1 < x+1 \leq 2$，即 $0 < x \leq 1$，得 $2(x+1) = 2x + 2$。

故  
$$
f(x+1) =
\begin{cases}
x^2 + 2x + 1, & -1 \leq x \leq 0, \\
2x + 2, & 0 < x \leq 1.
\end{cases}
$$
:::

✅ **关键要点**：  
- 分段函数的复合/平移/缩放等变换，**必须同步作用于每一段的定义域条件**；  
- 不可仅改写表达式而忽略定义域迁移，否则将导致函数失真；  
- 此操作是后续学习函数图像变换（如左右平移）与复合函数定义域分析的基础。
