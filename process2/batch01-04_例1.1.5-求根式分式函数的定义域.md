# 例1.1.5：求根式分式函数的定义域

> **题目**：求函数  
> $$
 f(x) = \sqrt{\frac{(x - 1)(x - 2)}{(x - 3)(x - 4)}}
 $$  
> 的定义域。

## 解题思路

函数由解析式给出，未附加实际背景，故定义域为使表达式**有意义**的所有实数 $x$。需同时满足：

1. **分母 ≠ 0**：$(x - 3)(x - 4) \neq 0 \implies x \neq 3,\, x \neq 4$；  
2. **被开方式 ≥ 0**（偶次根号下非负）：  
   $$
   \frac{(x - 1)(x - 2)}{(x - 3)(x - 4)} \geq 0.
   $$

## 解不等式

构造符号表或使用穿针引线法解分式不等式：

临界点：$x = 1, 2, 3, 4$（分子零点：1,2；分母零点：3,4）

| 区间             | $(x-1)(x-2)$ | $(x-3)(x-4)$ | 分式符号 | 是否满足 ≥ 0 |
| -------------- | ------------ | ------------ | ---- | -------- |
| $(-\infty, 1)$ | $+$          | $+$          | $+$  | ✅        |
| $(1, 2)$       | $-$          | $+$          | $-$  | ❌        |
| $(2, 3)$       | $+$          | $+$          | $+$  | ✅        |
| $(3, 4)$       | $+$          | $-$          | $-$  | ❌        |
| $(4, +\infty)$ | $+$          | $+$          | $+$  | ✅        |

考虑等号成立（分子为0）：$x = 1$ 或 $x = 2$ → 分式 = 0 → 允许（根号内可为0）；  
分母为0点 $x = 3,4$ → **必须排除**。

故定义域为：  
$$
(-\infty, 1] \cup [2, 3) \cup (4, +\infty).
$$

::: {#solution-115 .solution label="答案" type=solution}
$$
\boxed{(-\infty,\, 1] \;\cup\; [2,\, 3) \;\cup\; (4,\, +\infty)}
$$
:::
