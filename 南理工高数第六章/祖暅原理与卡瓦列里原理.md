# 祖暅原理与卡瓦列里原理

早在我国齐梁时代，数学家祖暅（祖冲之之子）在计算球体积时发现：**若两个立体在同一高度处的截面面积相等，则这两个立体的体积一定相等**。这一深刻洞察被称为**祖暅原理**。

17世纪，意大利数学家博纳文图拉·卡瓦列里（Bonaventura Cavalieri）独立提出类似结论，即：**若两个立体被一组平行平面所截，且所有对应截面面积均相等，则其体积相等**。该结论后称**卡瓦列里原理**（Cavalieri's Principle）。

::: {.note}
祖暅原理与卡瓦列里原理本质一致，是微积分诞生前对“体积可加性”与“截面累积”的几何直觉表达。它们为定积分定义立体体积提供了先验几何基础。
:::

微积分学的创立彻底改变了解决此类问题的方法——将体积视为截面面积函数 $S(x)$ 在区间上的**连续累积**，从而实现从离散类比到严格分析的跃迁。

延伸理解：  
- 该原理是**富比尼定理**在一维截面情形下的几何特例；  
- 是推导球体、椭球体、抛物面体等经典立体体积的通用起点；  
- 在现代数值模拟中仍作为网格剖分与体素积分的理论依据。
